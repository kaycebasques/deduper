The viewcode extension doesn't seem to do any caching to check if the code it's highlighting has changed, so any change in the project triggers highlighting of all the modules.

It would be good if it would e.g. keep a hash of the code in the pickled env and only write out the page if the code has changed, or e.g. look at the modification time of the source file (I'm not sure what approach Sphinx takes in general).

I think I might be able to implement it myself by using the `viewcode-find-source` event and making it return an empty tags dictionary if the file has not changed.
