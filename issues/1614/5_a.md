[Peter Davis](https://bitbucket.org/mrmagooey) you can access `BuildEnvironment` instance from `directive` class implementation as:

```
env = self.state.document.settings.env
```

ref: http://sphinx-doc.org/extdev/tutorial.html#the-directive-classes

Also you can access `BuildEnvironment` instance from `transform` class implementation as:

```
env = self.document.settings.env
```

`env` has all information to build documentation output such as `toc_secnumbers` property and methods to get doctrees.
