> [...] Would Docutils PDF from LaTeX make the first one about as wide as second one? 

Actually, the given examples are exactly as wide (100% linewidth because the input table width exceeds 40 characters.) 
So, lets compare 35 character wide simple tables.
~~~
By default, the Docutils LaTeX writer uses the grid widths and adds an
allowance. In the PDF, tables take about 75% of the available width
(just as the image below the tables).

.. table::
   
   =============== ===============
   A               B
   =============== ===============

.. table::
                            
   = = = = = = = = = = = = = = = = 
   A B C A B C A B C A B C A B C A 
   = = = = = = = = = = = = = = = = 

.. image:: img.png
   :width: 75%
   :height: 5px
   :align: center

With the :widths: grid option, there is no allowance.
The table with 2 columns is exactly 75% wide, the
table with 15 columns is considerably narrower.

.. table::
   :widths: grid
   
   =============== ===============
   A               B
   =============== ===============

.. table::
   :widths: grid
                            
   = = = = = = = = = = = = = = = = 
   A B C A B C A B C A B C A B C A 
   = = = = = = = = = = = = = = = = 

With :widths: auto, LaTeX fits the column widths to the content (just
like Sphinx output).

.. table::
   :widths: auto
   
   =============== ===============
   A               B
   =============== ===============

.. table::
   :widths: auto
                            
   = = = = = = = = = = = = = = = = 
   A B C A B C A B C A B C A B C A 
   = = = = = = = = = = = = = = = = 
~~~
Just try it yourself, `rst2latex example rst` followed by `pdflatex example.tex`...
