Quick reply: we will let LaTeX support `:width:` option soon, but it is not flagged as extremely urgent for the following reasons:

1.  Sphinx provides (and provided already in 2017) the `tabularcolumns` directive which affects only LaTeX rendering and allows there finer control (For example of use, see our own sphinx/doc/extdev/deprecated.rst)
2. I may be wrong (I am not connected to the site now, so can't search) but we did not receive user complaints so far about `:width:` being ignored by Sphinx LaTeX, apart from a recent one by a diligent user (#13700). ;-)

I will handle first the improvement alluded to in a previous comment so that cell contents with multiple paragraphs are better rendered when `tabulary` is used, and cells with lists or other display material will not trigger fall-back to `tabular`, so use cases of `tabulary` are more numerous.  I will need to examine in this process if long tables `longtable` can also improve via the same mechanism.
