All `make clean`, `-E` and `-a` options have different purposes.

* `make clean`: Removes all built files. It means next build will start with brand new state. `make clean html` is same as `make clean && make html`.
* `sphinx-build -E`: Ignores last built files. It also starts with brand new state. But, it does not remove old files. So some files might be remained if document structures changed.
* `sphinx-build -a`: Re-writes target files. It uses last built files if available. So it sometimes skips reading phase.

I suppose the execution time of `make clean html` and `sphinx-build -E` are almost same. But `sphinx-build -a` might be fast because it's a kind of incremental build.


As @jakobandersen said, `make` works as a wrapper of `sphinx-build` command. So `sphinx-build` doesn't have a proper way to know the old files are removed or not.
