So for now, as a workaround, I wrote a custom sphinx extension to overwrite the `dir` function to preserve the order from source instead of alphabetical during sphinx-build: 

```python
# patch_inherited_bysource_order.py
import builtins

std_dir = builtins.dir


def source_order_dir(obj):
    if isinstance(obj, type):
        return [name for cls in obj.mro() for name in cls.__dict__.keys()]
    return std_dir(obj)


def setup(app):
    print("Patching 'dir' function globally")
    builtins.dir = source_order_dir
```

and add it to your `conf.py` in the extensions:

```python
# conf.py
...
extensions = [
    ...
    "patch_inherited_bysource_order",
    ...
]
...
```

Tried on Sphinx==8.0.2, works for both inherited `bysource` and alphabetical order.
