Subject: When I turn my subsection headers into links to other documents, the localtoc sidebar shows those links with a literal block inside.

### Problem

When making the section headers in a document into links, either by using `:doc:` or `:ref:`, the headers then show up in the localtoc as literal blocks. I've stubbed out an example project in https://github.com/spencer-rig/sphinx-header-link-example to show the source that causes this. A screenshot of the output is [here](https://github.com/spencer-rig/sphinx-header-link-example/raw/master/screenshot.png)

#### Procedure to reproduce the problem

I make sure I'm in a fresh environment with `virtualenv .env && source .env/bin/activate`, then install dependencies with `pip install -r requirements.txt`. Then I build the document with `sphinx-build . build/`

#### Error logs / results

The screenshot above shows the output, and the generated html for the localtoc appears as:

```
<ul>
<li><a class="reference internal" href="#section-1-is-not-a-link">Section 1 is not a link</a></li>
<li><a class="reference internal" href="#section-2-is-a-link"><code class="docutils literal"><span class="pre">Section</span> <span class="pre">2</span> <span class="pre">is</span> <span class="pre">a</span> <span class="pre">link</span></code></a></li>
<li><a class="reference internal" href="#section-3-is-a-ref-link"><code class="docutils literal"><span class="pre">Section</span> <span class="pre">3</span> <span class="pre">is</span> <span class="pre">a</span> <span class="pre">ref</span> <span class="pre">link</span></code></a></li>
</ul>
```

#### Expected results

I think the localtoc should not put the `<span class="pre">` nor the `<code class="docutils literal">` blocks in the list-item links.
