### Describe the bug

Sphinx seems to be a bit random with how quotation marks are rendered in a functions parameter list.
We want double quotations to be used for strings and single quotations for enums.

### How to Reproduce

The following works correctly:

```
   .. method:: method(string="", enum='TEST', null_string)

      Description.

      :arg string: Description.
      :type string: string, (never None)
      :arg enum: Description.
      :type enum: enum in class type, (optional)
      :arg null_string: Description.
      :type null_string: string
```

However the quotations all become single when you add a default value to the last string parameter.

```
   .. method:: method(string="", enum='TEST', string2="Some String")

      Description.

      :arg string: Description.
      :type string: string, (never None)
      :arg enum: Description.
      :type enum: enum in class type, (optional)
      :arg string2: Description.
      :type string2: string
```
