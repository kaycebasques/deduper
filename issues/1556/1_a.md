Sphinx has autodoc which can extract (selected) bits of documentation from the code itself.

Sphinx also has linkcode, which can add links to documented code items.

It should be possible to use autodoc to extract full (project-relative) file paths and line numbers while it's doing its thing and inject that in a format string to get a direct link to the source in bitbucket or github or whatnot.
