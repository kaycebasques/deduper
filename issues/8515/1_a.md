    .. |subst| replace:: Substitution

_a.rst_:

    A: |subst|

_b.rst_:

    B: |subst|

The output is correct:

> A: Substitution
> 
> B: Substitution

But building the Sphinx projects yields these warnings:

    a.rst:2: WARNING: Undefined substitution referenced: "subst".
    b.rst:2: WARNING: Undefined substitution referenced: "subst".

Replacing the extension on _a.rst_ and _b.rst_ with _.txt_ suppresses the warnings. This is apparently because [Sphinx scans files with the _.rst_ extension twice](https://github.com/sphinx-doc/sphinx/issues/3432#issuecomment-280973758). I hope you agree that is very confusing, and the user should be able to use the _.rst_ extension also for included files?
