I use `add_index_to_domain` to add a custom index. However, `add_index_to_domain` does not seem to add any reference. I'd like to use

```
:ref:`myindex`
```

To do so, I found that I need to add a reference manually in `setup`:

```
from sphinx.domains.std import StandardDomain
from sphinx.domains import Index

class MARXParIndex(Index):
    name = 'myindex'
    localname = 'My cool Index'
    shortname = 'My Parameters'

    def generate(self, docnames=None):
        # do stuff here
        return '', False


def setup(app):
    app.add_index_to_domain('std', MyIndex)
    StandardDomain.initial_data['labels']['myindex'] = ('std-myindex', '', 'My cool Index')
    StandardDomain.initial_data['anonlabels']['myindex'] = ('std-myindex', '')
```

It would be good if `add_index_to_domain` took care of that automatically.

Note: I would have maked this as "Component: domains:std" but that label does not exist.
