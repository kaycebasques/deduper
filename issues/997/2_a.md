The problem is not specific to glossary items but to definition lists.  For example, the following will create a broken link in the index regardless of whether it's inside the "glossary" directive:

{{{
term1
    Description of term1.

```
.. index:: term-two
```

term2
    Description of term2.
}}}

Outside of a "glossary" directive, the following will create a valid link in the index but it breaks the definition list into two:

{{{
term1
    Description of term1.

.. index:: term-two

term2
    Description of term2.
}}}

Inside of a "glossary" directive, the above doesn't work because it only handles a subset of reST: terms followed by definitions.

I'm not sure if this problem is due the "index" directive or something related to how docutils parses definition lists.  It should be noted that following works as expected, creating a valid link in the index even though the "index" directive isn't at the save level as the next element:

{{{
- list-item1
  
  Paragraph under list-item1.
  
  .. index:: list-item-two
- list-item2
  }}}

---

With regards to your specific example though, the "index" directives are redundant since they use the same name as the following term which would otherwise be indexed automatically.  If you just remove the "index" directives, valid links should be created for each term.  

If you really want index entries to terms under a different name, you might try the inline {{{:index:}}} markup role http://sphinx.pocoo.org/markup/misc.html?highlight=index#role-index.  Alternatively, you could add multiple terms for the definition as described here http://sphinx.pocoo.org/markup/para.html?highlight=glossary#directive-glossary.
