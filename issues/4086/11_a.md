For my documentation I am setting `numfig_format` figure setting to `Figure %s`. I need to use the following custom CSS
```
span.caption-number:after {
   content: ": ";
   margin-left: -0.25em;
}
```
The reason for the margin correction is because Sphinx generates an additional space
```
<span class="caption-number">Figure 1 </span>
```
IMHO, `Figure 1: Some caption` looks better than `Figure 1 : Some caption`.

It would be great if the additional space is removed from the HTML output.

To summarize
1. Use `numfig_format` to switch between `Fig. 1` and `Figure 1`.
2. Control punctuation and spacing between figure label and its caption with CSS `after` selector.
3. For above to work seamlessly, the Sphinx would need to stop adding the additional space in the caption number `span` tag.
