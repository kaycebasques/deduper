Before I dive in, here's my proposal, what do you all think?

Adding a config setting `numfig_format_caption` that has the same options (a dict with keys 'figure', 'table', 'code-block' and 'section') and behavior as `numfig_format`, but its entries override the behavior of `numfig_format` only when generating output being used for a caption.

Any unset `numfig_format_caption` entries will default to the value of `numfig_format`'s

---

My first though was to create a setting that would just specify a separator, but this is probably about the same amount of work, and is more flexible, say, if someone wants their text to say "Figure x" but the figure captions to say "Fig. x:", which isn't so uncommon.
