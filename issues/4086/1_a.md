Since the numfig_format is used as caption prefix and also for referencing figures/tables etc., it is not possible to use different formats. I would like to have a reference in text as _"see Figure 1"_, and the caption of my figure should be 

_"Figure 1: Example image"_

Instead, with `numfig_format={'figure': 'Figure %s'}` I get 

_"Figure 1 Example image"_ (without colon)

The output in Latex pdf is correct, this only applies to the html output.

When I add the colon to the `numfig_format numfig_format={'figure': 'Figure %s:'}`, I also get the colon in the text reference, which I don't want to have. (And I have two colons in the caption of the latex output and no space between Figure and the number anymore).
