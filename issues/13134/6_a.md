@githubnmaurer One finds at https://www.latex-project.org/news/latex2e-news/ the PDFs giving a summary of LaTeX kernel changes, in particular regarding tagging support since 2022. The user interface has constantly evolved over this time so that it is very difficult to do anything stable here.  Besides this present issue is very broad, and one can check [there](https://latex3.github.io/tagging-project/tagging-status/) the status of various LaTeX packages versus tagging support.  The focus of the LaTeX team is to support tagging for bare documents using only LaTeX2e as in the legacy Lamport book.  Many old packages are not maintained anymore and some are used by us.  Also, the LaTeX team has announced only LuaLaTeX will be supported in future for full support. This causes a problem because for many years lualatex had a core security vulnerability so only updated systems are safe.  And many Sphinx users employ antiquated LaTeX distributions.  This all being said, if all which is at stake is some alt for graphics inclusion, it is part of the very recent LaTeX kernel additions I think, so probably we could try to do something. For this we need full-time LaTeX maintainers keeping in touch with a rapidly evolving upstream situation, or LaTeX contributors making PRs to support this on-going evolution.
