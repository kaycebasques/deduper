**Is your feature request related to a problem? Please describe.**

URLs for refefenced images have an undesirable underscore in them, e.g.
```
https://docs.bokeh.org/en/latest/_images/examples/basic/bars/mixed@2x.png
```
I would like these to be able to be:
```
https://docs.bokeh.org/en/latest/img/examples/basic/bars/mixed@2x.png
```

I was surprised to learn that this value `"_images"`appears to be hard-coded into the HTML builder:
https://github.com/sphinx-doc/sphinx/blob/c51a88da8b7b40e8d8cbdb1fce85ca2346b2b59a/sphinx/builders/html/__init__.py#L242

**Describe the solution you'd like**
I would like a configuration option, similar to `html_static_path` or `templates_path`, for controlling this location:
```
html_image_path = ["img"]
```

**Describe alternatives you've considered**

Before realizing that the location was hardcoded in the builder, I spent some time moving `_images` to `img` and updating references only to discover that it would not be sufficient to work.
