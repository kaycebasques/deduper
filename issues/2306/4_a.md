So I went ahead and implemented an extension similar to the regular `include` directive:
```python
import sphinx
from docutils.parsers.rst import directives

class IncludeIf(sphinx.directives.other.Include):
    option_spec = {
        'tags': str,
    }

    def run(self):
        env = self.state.document.settings.env
        condition = self.options.get('tags', None)
        if condition and not env.app.builder.tags.eval_condition(condition):
            return list()
        return super().run()

def setup(app):
    directives.register_directive('include-if', IncludeIf)
```

You can use it like this:
```
.. include-if:: featureX.rst
  :tags: fullDoc or supportFeatureX
```

The `tags` option supports multiple tags as shown. I hope this is of use for someone and might be even picked up in mainline, since it fixes some of the pain points of using `only` or `ifconfig` for including huge things like entire sections.

Caveat: If the tags are changed on subsequent runs, this will not be picked up. You must do a clean build when changing tags. If there is a way to fix this (even if it means that the whole document gets rebuilt, but at least automatically), please let me know.
