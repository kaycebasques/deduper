It depends to "section header under only directive" problem (that relates to #1488)

For now, it's difficult to fix soon by implementation.
As a workaround, `only` directive shouldn't have any sections.

---

For the record, let's see the internal.
This is a internal doctree output by pseudoxml before resolving only directive:

```
<document source="/path/to/issue2306/first.rst">
    <section ids="first-one" names="first\ one">
        <title>
            First one
        <section ids="heading-before-any-only-or-tags" names="heading\ before\ any\ only\ or\ tags">
            <title>
                Heading before any only or tags
            <paragraph>
                With some paragraph text.
            <target refid="mylinkname">
        <only expr="truetag" ids="mylinkname" names="mylinkname">
            <section ids="this-is-a-chunk-that-is-in-truetag" names="this\ is\ a\ chunk\ that\ is\ in\ truetag.">
                <title>
                    This is a chunk that is in truetag.
                <paragraph>
                    With some text under it
        <section ids="heading-outside-of-truetag" names="heading\ outside\ of\ truetag">
            <title>
                Heading outside of truetag
            <paragraph>
                This text refers to 
                <inline classes="xref std std-ref">
                    MyLinkName
                .
```

In this case, `only` node is hanging under "First one" section instead of "Heading before any only or tags" section. It is the cause of this ticket. 
Consequence of this, as you see, `<target refid="mylinkname">` inserted at the end of "Heading before any only or tags" section that is preceding of the "only" node.

OTOH, If `first.rst` doesn't have section under the only directive, internal doctree is changed as:

```
<document source="/path/to/issue2306/first.rst">
    <section ids="first-one" names="first\ one">
        <title>
            First one
        <section ids="heading-before-any-only-or-tags" names="heading\ before\ any\ only\ or\ tags">
            <title>
                Heading before any only or tags
            <paragraph>
                With some paragraph text.
            <only expr="truetag">
                <paragraph>
                    This is a chunk that is in truetag.
                <paragraph>
                    With some text under it
            <target refid="mylinkname">
        <section ids="heading-outside-of-truetag mylinkname" names="heading\ outside\ of\ truetag mylinkname">
            <title>
                Heading outside of truetag
            <paragraph>
                This text refers to 
                <reference internal="True" refid="mylinkname">
                    <inline classes="std std-ref">
                        Heading outside of truetag
                .
```

In this case, only node is hanging under "Heading before any only or tags" section and `<target refid="mylinkname">` inserted into just before "Heading outside of truetag" section.
