### Describe the bug

SVG inheritance diagrams are supposed to have clickable links for individual nodes. However, these nodes generate with invalid/broken links when the `dirhtml` builder is used.

### How to Reproduce

1) Create a venv (optional)

    ```sh
    python -m venv .venv
    . .venv/bin/activate
    ```

2) Install sphinx (also, make sure that graphviz is installed and dot is available on PATH)

    ```sh
    pip install --upgrade pip setuptools
    pip install sphinx==8.2.3
    ```

3) Create the minimal-ish example

    ```sh
    mkdir -p docs/devdoc mypkg

    cat >mypkg/__init__.py <<'EOF'
    class A:
        pass
    EOF

    cat >docs/conf.py <<'EOF'
    project = "mypkg"
    extensions = [
        "sphinx.ext.autodoc",
        "sphinx.ext.inheritance_diagram",
    ]
    graphviz_output_format = "svg"
    EOF

    cat >docs/index.rst <<'EOF'
    .. toctree::
        :titlesonly:

        devdoc/mypkg
    EOF

    cat >docs/devdoc/mypkg.rst <<'EOF'
    Works
    -----
    :py:class:`mypkg.A`

    Broken
    ------
    .. inheritance-diagram:: mypkg
       :parts: 1

    Target
    ------
    .. automodule:: mypkg
       :members:
       :undoc-members:
    EOF
    ```

4) Build the docs

    ```sh
    rm -rf .out
    python -m sphinx \
        --builder dirhtml \
        --verbose \
        --nitpicky \
        --fail-on-warning \
        docs .out/sphinx.dirhtml
    ```

5) Serve the generated docs

    ```sh
    python -m http.server -d .out/sphinx.dirhtml
    ```

6) Open `127.0.0.1:8000` in your browser, click on the `A` link and then on the `A` node in the inheritance graph (under the "Broken" header).

    Observe that the link embedded in the SVG redirects you to `http://127.0.0.1:8000/sphinx.dirhtml/devdoc/mypkg.html#mypkg.A` which doesn't exist. The correct link should be `http://127.0.0.1:8000/devdoc/mypkg#mypkg.A` which 1) doesn't have the `sphinx.dirhtml` prefix and 2) doesn't end in `.html` due to using `dirhtml`.

    Inspect the generated `.out/sphinx.dirhtml/_images/inheritance-*.svg` file and see that it contains the invalid `href`:
    ```svg
    <ns0:a ns1:href="../sphinx.dirhtml/devdoc/mypkg.html#mypkg.A" ns1:title="A" target="_top">
    ```

    Also, note that the ```:py:class:`mypkg.A```` reference under the "Works" header links to the correct page.
