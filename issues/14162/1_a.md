### Describe the bug

This is the successive issue of #14143. While most false warnings have been addressed by #14144, but not all of them are covered. We can still observe many correct translation are flagged on [the python docs translation dashboard](https://translations.python.org/build-details.html). Some python docs translation repos do not allow any build warning in their build workflows and hence being blocked by this issue.


### How to Reproduce

The followings are all valid translation across different language version of the python docs but now induce build warnings:

#### ~~1. Reordered hyperlink~~

resolve by #14172
