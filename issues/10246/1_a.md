### Describe the bug

Hi I have issue with Sphinx where my description text seems to overlap with the attributes and methods table. This happens when I add an indentation (Literal Block) to the class description. If my class description does not have any indentation, then the overlap issue does not happen. My expected behavior in the doc page is as follow:

Description, Attributes Table, Methods Table

but because of the indentation (literal block) I would get Description Attributes Table, Methods Table, Description (continued). Here the description overlapped the attributes & method tables. Example is shown on the screenshot. 
Thank you for helping.

### How to Reproduce

I created a python file with a class and description of the class. Inside the description, I've added indentation to create Literal Blocks

Class example:
```python
class ExampleModel:
    """
    ExampleModel
    Example:
      {
        "type": "example",
        "code": 200
      }
    """
    # ...
```

Generate the docs and the attribute and method tables will now appear before the description have finished.
