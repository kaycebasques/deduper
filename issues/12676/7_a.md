For the use of single quotes, it should be independent of the language actually. In french, the « » are used to *quote* text, but not to quote, e.g., an argument name. For quoting something like an argument name, I'd recommend either always using `'arg`' like in python *or* using <code>\`arg'</code> like in shell.

Here the quotes are relevant in the sense that they are markers, or HTML tags if you want (like `<b>`) but they do not have the same meaning as in literature IMO.
