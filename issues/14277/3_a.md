Several years ago I switched from ReadTheDocs to GitHub Actions, because the RTD infrastructure was very very slow. We also run into problems and requested an extended runtime for our open source project.

For us, a majority of the time was spend in linking the document. We have a huge set of auto generated documentation files derived from source code. Somehow I had the feeling at that time, that resolving references is an O(N²) problem in Sphinx, where it should be O(N) problem.

As far as I remember, you can push HTML content to RTD e.g. from GitHub Actions, right?  
If this API still exists. I recommend a speed comparison.

It doesn't solve the underlying problem (size of the repo and speed in Sphinx), but it would use modern/less restricted hardware.
