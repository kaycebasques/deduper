[dvipdfmx](http://project.ktug.org/dvipdfmx/) is a dvi to pdf converter which generally produces quite smaller files than PDFTeX, due to use of CFF compressed font format (for PostScript Type1 fonts). It is already used by Sphinx for Japanese documents which go via ``platex+dvipdfmx``. It would be nice to have ``latex+dvipdfmx`` also available as an option.

Admittedly ``xelatex`` engine uses internally ``xdvipdfmx`` which has a common code base with ``dvipdfmx``, hence to some extent adding ``latex+dvipdfmx`` looks redundant.

But there are some (minor) issues with ``xelatex`` (aspects of math typesetting, hyphenation problems for languages such as German when using traditional TeX fonts,...) in fact ``xelatex`` engine is best reserved for use with OpenType/TrueType fonts, and one may wish for whatever reasons to use some traditional TeX fonts for PDF output.

The main difference for the LaTeX file is that ``dvipdfmx`` should be added as document class option to inform packages such as ``graphicx`` about the driver and a few packages need some extra set-up like ``dvipdfm`` option rather.
