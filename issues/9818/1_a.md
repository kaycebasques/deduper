### Describe the bug

I have a class *histogram* with a method *\_\_eq\_\_*, which I'd like to document.

When I write

```
.. autoclass:: histogram
    :members:
    :special-members: __eq__
```

it doesn't work (no such method appears in the documentation). I tried to add `__eq__` to the list of `:members:` as suggested [here](https://github.com/sphinx-doc/sphinx/issues/2401#issuecomment-416091056), but it didn't work.

However, when I use a directive .. automethod::, it works, which looks like a bug. This works:

```
.. autoclass:: histogram
    :members:

    .. automethod:: __eq__
```

### Expected behavior

`special-members` should work.
