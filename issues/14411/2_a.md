IMO, this is a documentation problem:

While the `sourcecode` directive is an alias for ["code-block"](https://www.sphinx-doc.org/en/master/usage/restructuredtext/directives.html#directive-code-block), `code` is a compatibility syntax for the upstream [Docutils "code" directive](https://docutils.sourceforge.io/docs/ref/rst/directives.html#code) with a different set of options: 
- instead of *linenos* and *lineno-start*, `code` uses *number-lines*,
- *emphasize-lines*, *caption*, and *dedent* are not supported,
- *force* is only supported by Sphinx, not by Docutils,

Authors that want to use the Sphinx-only options should use "code-block" or "sourcecode".
Authors that want their source to be compatible with Docutils should use "code" and only options supported by Docutils.
