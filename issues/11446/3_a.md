Thanks for the reply. The `linkcheck_anchors_ignore` is to ignore _anchors_ btw, not base_urls. In the project I was working on I now set 

```python
linkcheck_anchors_ignore = ["/type-concepts-advanced"]
```

which works, so we're not blocked at the moment.

Alternatively, we could also ignore the base_url using

```python
linkcheck_ignore = ["https://microsoft.github.io/pyright/#"]
```
