> The `option` directive simply hasn't been yet added as a possible additional target. But it would not be trivial to add as [it is also a cross-reference target](https://www.sphinx-doc.org/en/master/usage/domains/standard.html#directive-option), so it would be quite difficult to make it work correctly if the option name is changed in the translations.

What about translating the entry which cross-references the `option` directive with the following form:

```rst
# Source (msgid)
:option:`--graphviz=<file>`

# Translation (msgstr)
:option:`--graphviz=<檔案> <--graphviz=<file>>`
```

Just like the way CMake Documentation did in its [`cmake.1.rst`](https://github.com/Kitware/CMake/blob/v3.28.5/Help/manual/cmake.1.rst?plain=1#L1344)

```rst
:manual:`CMake Presets <cmake-presets(7)>`
```

Is it possible to do so?
