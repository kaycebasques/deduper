As a temporary workaround you can set `SPHINX_AUTODOC_IGNORE_NATIVE_MODULE_TYPE_STUBS` to a non-empty value:

```console
SPHINX_AUTODOC_IGNORE_NATIVE_MODULE_TYPE_STUBS=1 sphinx-build ...
```

This makes autodoc import the native extension directly instead of executing the adjacent `.pyi` file, avoiding the forward-reference error. This workaround is being documented in #14563.

The tradeoff is that signatures or annotations available only in the stub may be omitted, so keeping this issue open for a proper fix.
