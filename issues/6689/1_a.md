**Is your feature request related to a problem? Please describe.**
Sometimes it is convenient to note a todo inline which is not possible using the todo admonition.
However there seems to be the todo role. This would require also creating a custom role.

**Describe the solution you'd like**
Using `` :todo:`todo message` `` should work the same as using the todo admonition.
