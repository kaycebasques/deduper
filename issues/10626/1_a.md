**Is your feature request related to a problem? Please describe.**
Syntax highlighting for inline code snippets via language specific roles is available since Sphinx 5.0.0. from #10251.

For such code snippets in sectioning titles, the highlighting is inhibited for PDF via LaTeX. It works in HTML.

Relates #10251, #10434, and #10506.

Proposed approach : main potential problems seem to have been fixed at https://github.com/sphinx-doc/sphinx/commit/213c29b3aa06d85fd63c2a21457493167c260aa2.  The next difficulties I see is that sectioning titles may be submitted to uppercasing. I feel the correct approach is to let the LaTeX writer create on the fly a new LaTeX macro for each inlined code snippet encountered, and insert these macro definitions in the preamble or in an external file which will be input.  Then they are immune to mistreatments such as uppercasing and compatibility with bookmarks can be achieved.
