> Btw, is it common to do that in markdown? I mean, is it supported by the MD specs? why not using real new lines?

To be honest, I was surprised to learn myself that such a feature exists. But some people just use it because it's a part of the specs – both the [original](https://daringfireball.net/projects/markdown/syntax#p):

> When you do want to insert a `<br />` break tag using Markdown, you end a line with two or more spaces, then type return.

and [CommonMarkdown](https://spec.commonmark.org/0.30/#hard-line-break), example 633:

> A line ending (not in a code span or HTML tag) that is preceded by two or more spaces and does not occur at the end of a block is parsed as a hard line break (rendered in HTML as a `<br />` tag):
