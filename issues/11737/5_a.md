I think that the biggest problem here is that gettext does not preserve important newlines in this situation. So if the text has line breaks in the source text and it is still one paragraph, it should be one `msgid` bit with line breaks `\n`. Unfortunately all new lines are converted to space so `  \n` generates forced line break but  `   `  will not.

Same problem is with MyST line break `\` which works only if it is followed by real new line but it is not preserved during translation.
