I think this comes down to how the `:annotation:` option works on `autodata`, not a difference between `autodata` and `automodule`.

In your example you have:

```rst
.. autodata:: some_module.some_var
   :annotation:
   :noindex:
```

When `:annotation:` is used without a value, autodoc suppresses the introspected type hint and value in the output. That is documented here:

https://www.sphinx-doc.org/en/master/usage/extensions/autodoc.html#directive-option-autodata-annotation

> If `:annotation:` is used without arguments, no value or type hint will be shown for the variable.

So the bare `:annotation:` flag is easy to read as “show the annotation,” but it actually does the opposite. That likely explains why `automodule` looks correct (it doesn't use that option) while standalone `autodata` shows only the name/header.

Try removing `:annotation:` entirely:

```rst
.. autodata:: some_module.some_var
   :no-index:
```

If you want the type hint but not the runtime value, use `:no-value:` instead:

```rst
.. autodata:: some_module.some_var
   :no-value:
   :no-index:
```
