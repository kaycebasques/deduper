Even if a project has no python module index (e.g. it is not a python project and nothing is marked with `:py:mod:`), the reference label `modindex` is generated. I can have 

```
* :ref:`modindex`
* :ref:`genindex`
* :ref:`search`
```

in my index.rst and the link to the module index just leads to a non-existing file.

I don't think this is important at all (after all who sets links to a module index if he does not wont one to be generated), I just thought I'll point that out when I saw it.

This is mostly relevant in conjunction with user defined indexes, because if I use `add_index_to_domain`, I cannot use `html_domain_indices = False` at the same time, because that disables all domain indices.
