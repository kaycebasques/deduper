> As to my understanding it's impossible to define such a style, because there is way to describe a CSS selector for class methods.

**Not impossible, but...** The usual solution (I've considered the problem you're raising years ago) is to break up things in the `.rst` and use [`.. class::`][1] -more specifically [`.. rst-class::`][2] in Sphinx- e.g:

```.rst

.. autoclass:: MyClass

    .. rst-class:: the_instance_method_css_class_selector

        .. automethod:: my_instance_method::

    ..

    .. rst-class:: the_class_method_css_class_selector

        .. automethod:: my_class_method::

    ..
```

The other *workaround* being the usual custom directive magic in `conf.py`... (Recent and related [How to order class attributes before methods with autoclass in sphinx-docs?][3])
