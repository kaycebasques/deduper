>  E.g. properties could get a different color then methods.

There are [Accessibility](https://en.wikipedia.org/wiki/Accessibility) issues with color coding stuff. Generally theme designers take this into account because it's a design issue that's outside the skillset of most devs. So be advised that if you think about deviating from the usual theme design you might be creating accessibility issues for a number of users without being aware of it. There are likely good reasons why a theme (and RTD theme has had plenty of professional designer support) is organized the way it is. So if a feature isn't present there are also, likely, reasons for the omission that might elude us,
