I can't see the patch, but this sounds like something I could use right now. What I'd _like_ to be able to do is this:

``` rst
.. toctree::
    ...
    :hidden:
```

I can't add custom options to the various entries created by `sphinx-apidoc`.

The ability to include might be one alternative. Then one could do something like this:

``` rst
# _toctree.rst
.. toctree::
    :maxdepth: 2
    :hidden:
```

``` rst
# _automodule.rst
.. automodule::
    :private-members:
    # ...
```

``` sh
sphinx-apidoc --toctree-include=_toctree.rst --automodule-include=_automodule.rst ...
```

These would compete with `--no-toc`, so resolution behaviors would have to be figured out (e.g., `--no-toc` trumps `--toctree-include`, latest on the command line wins, etc.).
