>Looking at the sphinx application it looks like it would be possible to transfer these methods

It would be better to add handlers for the "format" instead of the "builder". It means this code will add a pair of handlers to the HTML supporting builders, not only for HTML.
```
app.add_node(some_node, html=(visit_some_node, depart_some_node)
```

I think there are many kinds of builders that supports HTML; singlehtml, dirhtml, qthelp, devhelp, epub, and so on. So I'd like to change the `add_node` API to support them all at once.
