I see. According to the [standard](https://en.cppreference.com/w/cpp/language/name.html), a valid C++ identifier can start with an XID_Start Unicode character, and be followed by an XID_Continue Unicode character. There are [quite a few](https://www.unicode.org/Public/UCD/latest/ucd/DerivedCoreProperties.txt) of them though.

The issue is discussed in the README of the Rust crate [unicode-ident](https://github.com/dtolnay/unicode-ident).

I am not sure if it is reasonable, or indeed even possible, to encode these properties in a Regex. Also, I am not sure if these would be valid C identifiers.
