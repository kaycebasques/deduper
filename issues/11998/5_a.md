Hi, the issue likely arises because `sphinx.ext.autosummary` doesn't automatically include `.. autofunction::` directives in the generated `.rst` files. As a result, the functions appear without linked documentation.

A quick manual fix is to explicitly add `.. autofunction::` before each function entry in your `.rst` files.

An automated solution is to use the `sphinx.ext.autodoc` extension along with the `autodoc_default_options` setting (note: [autodoc_default_options](https://www.sphinx-doc.org/en/master/usage/extensions/autodoc.html#confval-autodoc_default_options) replaces the deprecated [autodoc_default_flags](https://www.sphinx-doc.org/en/master/extdev/deprecated.html), which was removed in Sphinx 4.0).  like this:
```python
extensions = [
    # ... your other extensions ...
    "sphinx.ext.autodoc",
]

autodoc_default_options = {
    "members": True,
    "undoc-members": False,
    "private-members": True,
}
```
