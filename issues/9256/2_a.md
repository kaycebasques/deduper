I think it can be time-consuming work for a real worker to go around to check for misplaced line numbers when someone updates a document or a target file.

This proposed feature would greatly reduce the time and effort of such people.
However, I think that this feature is not for everyone. Therefore, I think that the maintenance cost in the future is not worth it if it is built into Sphinx itself.

So, how about providing a hook for literalinclude directives in Sphinx itself, so that anyone can implement such a request with an extension?
