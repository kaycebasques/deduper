Update: they actually aren't supposed to be escaped in xhtml with utf-8. I messed around with the template until the code put this in the header:

`<meta http-equiv="Content-Type" content="text/html; charset={{ encoding }}" />`
instead of 
` <meta charset="{{ encoding }}" />`

In `layout.html` of the basic theme there's this if statement: 

```
    {%- if use_meta_charset or html5_doctype %}
    <meta charset="{{ encoding }}" />
    {%- else %}
    <meta http-equiv="Content-Type" content="text/html; charset={{ encoding }}" />
    {%- endif %}
```
And the first clause triggers. If you force it to use the second, things work great all the way to kindle.
