### Problem
I try to generate html from a Python docstring containing a list of parameters with the same name but a different type. Unfortunately, only the first parameter is associated with a type in the generated output, others types are blank while description are fine.

#### Procedure to reproduce the problem
Build html for the following `.rst` source:

```python
.. py:function:: foo(bar)

   The docstring

   :param bar: A parameter
   :type bar: str
   :param bar: A parameter bis
   :type bar: int
   :param bar: A parameter tri
   :type bar: float
```
