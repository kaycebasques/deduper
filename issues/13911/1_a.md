**Is your feature request related to a problem? Please describe.**
When translating a Web page generated by Sphinx using Web browser's automatic translation, the signature of the API entries are translated too, while only the explanation should be.

**Describe the solution you'd like**
The solution is to use the [translate](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes/translate) global attribute in the enclosing HTML element.

**Describe alternatives you've considered**
No alternative considered.

**Additional context**
The `notranslate` class is already inserted in the generated HTML code since v1.7, but, according to my test, automatic translation of Google Chrome does not honor it.
