You mean in `:lines:` https://www.sphinx-doc.org/en/master/usage/restructuredtext/directives.html#directive-option-literalinclude-lines?

What's the exact syntax? It's a bit tricky because `-` is already used as a range indicator. So we'd have to resort to some kind of escaping or parentheses. Something like ("show first and last line"):
```
.. literalinclude:: example.py
   :lines: 1,(-1)
```

Given that notation is not straight forward and fixed line numbers have their limits anyway, the extension may not be worth it. For more complicated situations you could write and call a preprocessing function in conf.py that creates a stripped-down version of the file and then you can `litteralinclude` that entirely.
