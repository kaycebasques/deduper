**Is your feature request related to a problem? Please describe.**
Let's say I have a JSON file, and I wish to show some schema-related keys. I want to have its last line, containing a closing brace, always shown such that the syntax highlighter renders correctly.

**Describe the solution you'd like**
Allow indexing from the end of the file using a negative number, as one would do in Python code.

**Describe alternatives you've considered**
I've tried to use end-before, but JSON doesn't allow comments, so non-trivial to add markers. Using a brace for end-at may match other closing braces in the file as well.
