**Describe the bug**

Using a colon in the property's description, treats the leading text as the return type, breaking documentation.

**To Reproduce**

```py
import random

class Test:
    @property
    def test(self) -> str:
        """
        Returns one of: ``"Yes"`` or ``No``.
        """
        return random.choice(["Yes", "No"])
```
