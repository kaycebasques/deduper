**Describe the bug**
When using autodoc to document a class with an attribute, both `members` and `undoc-members` needs to be specified for the attribute to show up.

**Expected behavior**
I'd expect one of them to be enough. Now it seems that the attribute is both documented and undocumented, which is weird.

**To Reproduce**
Here's a minimal project:

```python
# conf.py
import os
import sys
from pathlib import Path

# Insert root folder to path
_root = Path(os.path.realpath(__file__)).parent.parent
sys.path.insert(0, str(_root))

extensions = ['sphinx.ext.autodoc']
exclude_patterns = ['_build']
```

```python
# package.py
class A:
    attr: str = 1
```

```rst
Package
=======

.. autoclass:: package.A
   :members:

.. autoclass:: package.A
   :undoc-members:

.. autoclass:: package.A
   :members:
   :undoc-members:
```
