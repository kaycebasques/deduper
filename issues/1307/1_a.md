Autosummary creates a longtable in latex like this:

\begin{longtable}{ll}
...

Therefore lines does not break. This produces a lot of overfull errors because the description is always too long. 

I think it would be better if the directive creates something like this:

\begin{longtable}{p{.5\textwidth}p{.5\textwidth}}
