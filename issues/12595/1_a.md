### Describe the bug

When running `./make gettext` on Windows, the command fails with **TypeError:** _expected str, bytes or os.PathLike object, not NoneType_. (On Linux it works without issue, as well as `./make html` is ok)



### How to Reproduce

To reproduce this you can clone the repo `https://github.com/SabNK/kuwaiba_docs` install requirements.txt and then run `./make gettext`
