Yes, you can't use XMLHttpRequest or fetch it with a file:// url.  The search index is loaded using the jsonp method (i.e. via a script tag) which does work with file:// urls.  Currently snippets are generated by fetching the actual html page, which means a separy copy of the page is not required for snippet generation.  Ll

To make snippets work with file://, the text content of every document would need to be additionally stored in jsonp format.  To avoid additional space usage in all cases, this should probably be an option defaulting to false.
