I have notice that `code-block` layout changes depending on whether line numbers are included. Indeed the text background width is shorter with numbers.

Try for instance

```
.. code-block:: python
   :caption: test
   :lineos:

   import sys

```

The result is 
![screenshot from 2016-04-06 10 39 17](https://cloud.githubusercontent.com/assets/6704112/14310745/e9236094-fbe3-11e5-8cbd-c7aa08f0f0d3.png)

while with

```
.. code-block:: python
   :caption: test

   import sys

```

is 

![screenshot from 2016-04-06 10 41 02](https://cloud.githubusercontent.com/assets/6704112/14310780/12cd2416-fbe4-11e5-8a63-3d866d36fb9f.png)

 That's quite annoying because I may want to have some code blocks with line numbers, but other without: the overall page layout is then a mess.
