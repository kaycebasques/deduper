### Describe the bug

When using a TypeVar with `covariant=True` as a type for a dataclass field, for some reason there is a `+` prepended to the type, and then the type reference is not found. In my code, the dataclass was generic for the typevar, but I've found that making the dataclass generic is not required to reproduce.

For some reason, it only seems to happen when the TypeVar is covariant. This seems to imply that sphinx is taking a look at the innards of the TypeVar. I also tried on sphinx 6.1.3 and it had the same failure.

### How to Reproduce

# repro.py
"""
..  py:class:: TestAType(\
        "TestAType", bound=TestA, covariant=True)
    A typevar for test a types

"""
from typing import TypeVar, Generic
import dataclasses

class TestA:
    pass

TestAType = TypeVar(
    "TestAType",
    bound=TestA,
    covariant=True,  # Comment out this line and problem goes away
)

@dataclasses.dataclass
class TestB:
    test_a: TestAType
