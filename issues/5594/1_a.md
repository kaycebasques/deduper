### Problem
- intersphinx: cache is not updated when no files are updated on incremental build
- see #5072 (it was merged once, but reverted at #5525).

#### Procedure to reproduce the problem
```
$ make html
(wait for invalidation of cache)
$ make html  # => fetching remote inventories, but not cached.
```

#### Expected results
- Remote inventories are cached even if no documents are changed.

- OS: Mac
- Python version: 3.7.1
- Sphinx version: 1.8.1
