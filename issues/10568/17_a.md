# Workaround for users

I've realised there's a simple workaround that works reasonably well if you have a small number of things to fix up (as my tiny library does). You can use the [`autodoc-process-signature` event](https://www.sphinx-doc.org/en/master/usage/extensions/autodoc.html#event-autodoc-process-signature) to add the type parameters to the start of the parameter list, like this (in your conf.py):

```python
def process_signature(app, what, name, obj, options, signature, return_annotation):
    if what == "class":
        if name == "aioresult.Future":
            signature = "[ResultT]" + (signature or "")
        elif name in ("aioresult.ResultBase", "aioresult.ResultCapture"):
            signature = "[ResultT_co]" + (signature or "")
    return signature, return_annotation

def setup(app):
    app.connect("autodoc-process-signature", process_signature)
```
