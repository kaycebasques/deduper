The `Contents` in the page footer comes from the table of contents. As no new chapter has yet started the footer is not changed. One could imagine for example render the contents of the `startdoc` as an Abstract. But this would possibly break existing things.

Personally I find that sphinx-quickstart's way of putting a default line "Contents:" is confusing for latex target. latex writer puts the `\tableofcontents` command before anything else found in `startdoc`. Hence `Contents:` ends up on a page of its own after it. As I was disconcerted by that when I started using Sphinx I have gotten in to the habit to put contents in `startdoc` only for testing small rst snippets. For real documents I don't have any text contents there. I wonder what other people do :-)
