Subject: Sphinx with autodoc and napoleon tries to create cross-reference links on the items in an "Attributes:" section that document public instance attributes of a class.

### Problem

We are using Sphinx with autodoc and the napoleon extension for a Python project. We are using "Attributes:" sections in class docstrings to describe the public instance attributes of the class that are not defined as Python properties.

This works fine, except that Sphinx tries to create links on the attribute names. It attempts to locate the target of the link automatically and seems to search all classes for potential targets. Sphinx uses for example Python properties in *other* classes as potential targets.

That behavior is not understandable for me. An item in an Attributes section stands on its own, i.e. should be considered its own target, so I don't understand why a link on that attribute would make any sense?
Also, why are *other* classes searched for a property with that name?

In cases where more than one  other class has a Python property with the name of an item in the Attributes section, the following warning is raised:

```
pywbem/cim_obj.py: docstring of pywbem.CIMInstanceName:: WARNING: more than one target found for cross-reference u'host': pywbem.WBEMListener.host, pywbem.WBEMConnection.host
```
See our issue pywbem/pywbem#761 for more details on this particular case.

#### Procedure to reproduce the problem
```
PYTHONPATH=. sphinx-build -b html -v -d build/doctrees -c . . build/html
```

With the following `test.py` file in that directory:
```
#!/usr/bin/env python

class B1(object):
    """A B1"""

    @property
    def name(self):
        """Name of the B1."""
        return 'dummy'

class B2(object):
    """A B2"""

    @property
    def name(self):
        """Name of the B2."""
        return 'dummy'

class A(object):
    """
    An A.

    Attributes:

      name (unicode): Name of the A.

      foo (int): A foo.
    """

    def __init__(self, name, foo):
        """
        Initialize an A.

        Parameters:

          name (str or unicode): Name of the A.

          foo (int): A foo.
        """
        self.name = to_unicode(name)
        self.foo = foo
```
