It turnes out that this is an issue related to `importlib.metadata.version`. I wanted to get the version of the package dynamically in `conf.py`:
```python
from importlib.metadat import version

release = f"v{version('timewise')}"
```

This caused the error above. Even just importing the `version` function even causes the error. 

The obvious solution is to hardcode the `release`, so feel free to close this issue if this is not something considered `sphinx` related.
