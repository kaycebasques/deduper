@arthur-tacca so basically what you want is the functionality of [`napoleon_use_rtype`][1] but for autodoc because you don't want to use the napoleon extension?

This is a reasonable FR to add an option to autodoc but not to change the default behavior of the extension because you're asking every other user to adopt your preference.

As for individually grouping types that's just wrong because the return types can be a function of the parameters captured via overload. You have to manually document them using overload and then selectively list them. The possible combinations are just too complex to arbitrate a default extension behavior in the return field. But you do have a use case for wanting to add types to the list that are linked as URLs instead of with cross-reference styling.
