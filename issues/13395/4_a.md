As you mentioned, it can be challenging for speakers of Latin-based languages to support languages with different character sets like CJKV. Currently, my concern is that the Japanese support in Sphinx's search functionality is quite incomplete. While options like janome, mecab, and tinysegmenter are available, giving the impression of robust Japanese search capabilities, the reality is that the search function barely works for Japanese, as noted in the initial comment.
One potential solution could be to create a more extensible implementation for the word splitter in Python and the splitQuery in JavaScript, allowing them to be released as a unified extension. This could make it easier to improve and maintain Japanese search support.
