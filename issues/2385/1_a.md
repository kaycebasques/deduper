I'm working on a large documentation project for a a multi-language tech project, and have code that looks something like this:

```
Welcome to the docs!

.. only:: python

  Using with Python
  ------------------------

  Here's how to use this project with Python!

.. only:: java

  Using with Java
  ---------------------

  Here's how to use this project with Java!

Here's some generic text that will be built and shown regardless of language!

.. etc etc etc
```

What I would expect to happen here, is that if I've properly set the `python` or `java` variables (which I have on the CLI by modifying the Makefile), then I would see something specific outputted for each language. So if I built my project for `python`, I should ONLY see the Python section.

What happens, instead, is this:
- The sections are outputted correctly for the desired language.
- The text BELOW the sections that is NOT bound to a specific language is bubbled UP above the language-specific content.

So, in the end, my document looks like this (when built for python):

```
Welcome to the docs!

Here's some generic text that will be built and shown regardless of language!

Using with Python
------------------------

Here's how to use this project with Python!
```

This seems really 'off' to me, it looks like it may be a bug in the processing.
