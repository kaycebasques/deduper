I investigated this issue locally while reproducing the corresponding CPython issue (`python/cpython#125910`).

From what I found:

- `:synopsis:` is stored as a plain string via `domain.note_module()`.
- `PythonModuleIndex.generate()` then uses `descr=module.synopsis` directly when creating the `IndexEntry`.
- As a result, inline markup such as `:pep:`, `:class:`, and inline literals remains unparsed and is emitted into `py-modindex.html` as plain text.

I'd be interested in working on a fix. Since this issue is assigned to you, would you be okay with me opening a PR? Also, do you have a preferred approach for where the inline markup should be parsed (when recording the synopsis, while generating the index, or later during rendering)?
