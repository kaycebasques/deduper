Thanks for the report @cacti77 - I could be mistaken, but I think there are two things to note here:

  * The [`doctest.SKIP`](https://docs.python.org/3/library/doctest.html#doctest.SKIP) flag seems designed to skip entire tests, not individual lines.
  * Our documentation doesn't make this clear, but the `doctest` options should be specified as an `:options:` clause on the `testcode` directive; migrating to something like the example below should allow you to configure `+SKIP`:

```rst
.. testcode::
   :options: +SKIP

   x = 10
   x += 10
   print(x)

.. testoutput::

   10
```

This should skip the test, meaning that it won't contribute towards failing the build despite the possibility (actuality, in this case) that the in it fails to evaluate to the expected output.

I think we should update the Sphinx documentation to clarify the latter point.
