### Describe the bug

Since 8.2.0 the html builder creates an empty _sources/ directory, even if `html_copy_source` is set to `False`. This was introduced by commit 285908aa073e5320d5f5a8b4648a2265c76a3f32.

### How to Reproduce

```bash
echo "" > index.rst
echo "html_copy_source = False" > conf.py
sphinx-build -M html . _build
ls -d _build/html/_sources
```
