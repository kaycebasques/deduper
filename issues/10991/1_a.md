### Describe the bug

Accord ing to [this](https://github.com/sphinx-doc/sphinx/blob/master/doc/extdev/appapi.rst), the callable passed through the parse_node parameter of the add_object_type method takes two arguments : a string, and a docutils node.

However, the very conf.py of this documentation defines a function with three parameters. When trying to pass a function with two parameter, the build fails when passing it three parameters, `self.env`, `sig` and `signode` - and based on the doc, what these are is anyone's guess.

### How to Reproduce

Include this as an extension, and load it from the conf.py
```py
def parse_article_node(st, nod):
    pass

def setup(app):
    app.add_object_type("article", "artref", parse_node=parse_article_node)
```
