As changed IDs will affect all websites that link to Docutils/Sphinx-generated page fragments, this must be guarded with an opt-in setting.

I would treat (de-)capitalization different from allowed characters, as the rationale here is not compatibility with all output formats but author convenience (linking to a capitalized section in running text).

Getting a new refname/ID framework right is a quite complex issue, so I propose to use the [Docutils EP framework](https://docutils.sourceforge.io/docs/eps/) for discussion and planning.
