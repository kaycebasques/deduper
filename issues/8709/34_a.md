Given that there is an easy workaround (use a section title or an explicit target with leading letter), adding some "magic" remedy for digit-only sections may be more trouble than its worth.

An option to allow more permissive rules for ID formation will solve both, this issue and the issue of auto-generated IDs for sections that don't use the Latin alphabet.
