> It comes from the node ID generation rule of docutils; the core library of Sphinx. It was defined to support many kinds of formats. 

The rationale and details of this design decision are explained in https://docutils.sourceforge.io/docs/ref/rst/directives.html#identifier-normalization
There is an open [feature request for less restrictive IDs](https://sourceforge.net/p/docutils/feature-requests/68/)
For the original question: setting an [id-prefix](https://docutils.sourceforge.io/docs/user/config.html#id-prefix) will keep permanent IDs on section headings starting with a number since Docutils 0.18, so this can provide a workaround in future Sphinx versions.
