IMO, it would be nice if an extension copies JS and CSS files automatically.
For example, you can do it with following code:
```
def setup(app):
    app.add_js_file('path/to/your.js')
    app.connect('build-finished', on_build_finished)

def on_build_finished(app, err):
    if err is None and app.builder.format == 'html':
        # build succeeded (for HTML)
        import os
        from sphinx.util.fileutil import copy_asset_file
        copy_asset_file('path/to/your.js', os.path.join(app.outdir, '_static'))        
```
