### Describe the bug

Sphinx Napoleon does not seem to parse Google-style docstring with variables in backticks well.

### How to Reproduce

## Reproducing Bug

Here is a minimal example to reproduce the bug.

```
.
|-- conf.py
|-- src
    |-- __init__.py
```

In `conf.py`:

```py
extensions = [
    'sphinx_rtd_theme',
    'sphinx.ext.autodoc',
    'sphinx.ext.napoleon',
    'autoapi.extension',
]

project = 'Docs'

autoapi_type = 'python'
autoapi_dirs = ['src']

html_theme = 'sphinx_rtd_theme'
```

In `src/__init__.py`:

```py
def setup_logging(save_path=None):
    """Set up logging configuration.

    Args:
        save_path (str, optional): If given, logs will also be saved to a local
            file. Defaults to None.

    Returns:
        None or str: If `save_path` is provided, returns the path to the log
            file.
    """
    pass
```

Then generate the doc with `sphinx-build -M html . _build`.

## Output with Bug

The "Returns:" message is in bold and the spacing is also wrong.

