AFAIK, (old?) MacOS also uses case-insensitive filesystem...

On my macbook air, it is easily reproduced:
```
$ uname -a
Darwin deneb.local 16.4.0 Darwin Kernel Version 16.4.0: Thu Dec 22 22:53:21 PST 2016; root:xnu-3789.41.3~3/RELEASE_X86_64 x86_64
$ echo Uppercase > Colorbar.rst
$ echo lowercase > colorbar.rst
$ ls -l
total 8
-rw-r--r--  1 tkomiya  staff  10  4 22 19:33 Colorbar.rst
$ cat Colorbar.rst
lowercase
```

Unfortunately, two major OS chooses case-insensitive file system by default. So we need to avoid such trouble.
