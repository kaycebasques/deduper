Error: `toctree references unknown document` for class and function with same name, one uppercase, one lowercase. 

### Problem

Having a module which contains a class `Colorbar` and a function `colorbar`, it seems impossible to get a working documentation out with autodoc and autosummary. 

#### Procedure to reproduce the problem
```
class Colorbar():
      # ...

def colorbar():
     # ...
```

result when calling `make html` is 

    D:\xyz\doc\source\_as_gen\colorbar.rst:29: 
    WARNING: toctree references unknown document ' _as_gen/colorbar.colorbar'

There is a document 
`_as_gen\colorbar.Colorbar.rst` produced. But no `_as_gen\colorbar.colorbar.rst` (probably as expected due to the os not differentiating between upper and lower case).

### Reproducible project / your project

A runnable example can be found here:

https://github.com/ImportanceOfBeingErnest/sphinx-mwe/tree/master/sphinx-upperlowercase

### Environment info
- OS: Windows 8.1
- Python version: 2.7
- Sphinx version: 1.7.1
