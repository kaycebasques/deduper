The one hard thing is that while toctree is usually just `ul->li-a` or `ul-li-ul-li...->li-a`, you can end up with some nontrivial content in the a node (like pre if a title has text wrapped in ``code``).  You can also get at least one p if `:caption:` is used, etc.  So while this would be very helpful in general, I'm not sure what the datastructure shoud look like that comes out to allow effective and complete templating.
