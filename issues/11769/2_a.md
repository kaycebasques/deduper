This behavior is years old and I wouldn't be surprised if it predates migration of the Sphinx project to GitHub, if that's the case the original reasoning might have been lost during the migration.

An educated guess would be that's it's preferable during the first step of docs generation not to include all the modules in `index.rst` because it's very likely any mistakes in `modules.rst` would break the build process. Thus it's preferable not to link since it increases the chances of a beginning Sphinx user successfully completing their first build.
