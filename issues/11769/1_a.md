### Describe the bug

Hello! First of all, I really love the work you are doing! Generated `index.rst` does not contain link to `modules.rst`, even though it is generated. I'm wondering whether this behavior is expected and if yes, what are the reasons?

### How to Reproduce

```bash
sphinx-quickstart -p project -r v1 -a author -l en --sep --extensions 'sphinx.ext.autodoc' --extensions 'sphinx.ext.autosummary' --extensions 'sphinx.ext.napoleon'
```
generates

index.rst:
```rst
.. project documentation master file, created by
   sphinx-quickstart on Fri Nov 24 08:49:00 2023.
   You can adapt this file completely to your liking, but it should at least
   contain the root `toctree` directive.

Welcome to project's documentation!
==============================================

.. toctree::
   :maxdepth: 2
   :caption: Contents:
 


Indices and tables
==================

* :ref:`genindex`
* :ref:`modindex`
* :ref:`search`
```
modules.rst:
```rst
project
=====================

.. toctree::
   :maxdepth: 4

   root_module

```
root_module.rst contains all valid submodules declarations.

Basically, what I'm currently doing for a workaround is:
```bash
sed -i "/:caption: Contents:/a\ \n   modules" "source/index.rst"
```
