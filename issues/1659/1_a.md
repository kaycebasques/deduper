I don't really understand what's going on here, but when I am using autoclass_content = 'both' and I put a :param: entry in my class docstring that wraps, it works, but if I put it in the **init** docstring, it doesn't. The error is this:

/Users/radix/Projects/effect/effect/**init**.py:docstring of effect.TypeDispatcher:4: WARNING: Field list ends without a blank line; unexpected unindent.

Here's the _failing_ example:

```
#!python

class TypeDispatcher(object):
    """
    An Effect dispatcher which looks up the performer to use by type.
    """
    def __init__(self, mapping):
        """
        :param collections.Mapping mapping: A mapping of intent type to
            performer.
        """
```

The following works:

```
#!python

class TypeDispatcher(object):
    """
    An Effect dispatcher which looks up the performer to use by type.

    :param collections.Mapping mapping: A mapping of intent type to
        performer.
    """
    def __init__(self, mapping):
        """
        """
        self.mapping = mapping

```
