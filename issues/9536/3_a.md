We make extensive use of the glossary too, see: https://docs.blender.org/manual/en/3.0/glossary/index.html

Many items that may be used in a definition lists don't belong in a global glossary.

- Having the reference definition above a title makes sense to use the title text, avoiding redundant repetition.
- Having the reference text above a regular paragraph of text makes sense not to interpret the paragraph as the title.

Having the reference above a definition list entry in my opinion makes sense to use as the reference title as there is no confusion, as to what the reference if referring to. If for some reason this is not the intended outcome, the reference could be added in the definition body.
