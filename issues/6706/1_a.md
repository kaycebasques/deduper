Lazy image loading is coming to the web soon (see whatwg/html#3752)! I think it would be very nice if Sphinx was able to support this web feature. This would be especially beneficial for documentation pages that are populated with lots of image content and large multi-megabyte vector graphics etc.

A simple `:loading:` option for the ["image" directive](https://www.sphinx-doc.org/en/master/usage/restructuredtext/basics.html#images) that corresponds to the `loading` attribute of the `<img>` HTML element would need to be added in order to fulfill this feature.
