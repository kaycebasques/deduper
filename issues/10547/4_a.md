You should be able to trigger a search using [searchtools.js](https://github.com/sphinx-doc/sphinx/blob/5.x/sphinx/themes/basic/static/searchtools.js) and the `searchindex.js` file that is created when your project is built.
With this, you can get a working search.
However, there are some challenges:
1. You need to make sure that the 3rd party app always gets the updated `searchindex.js` file when the Sphinx-generated documentation page is updated.
2. To make use of the preview feature, you need to be able access the HTML files, so you either need to move a full copy of your project to the 3rd party app or to somehow enable the documentation page to serve them without running into issues with cross-domain security features.

In case there is a serious interest in this, one could write a brief tutorial based on the experiences of people who have actually deployed such a feature.
