It seems to be a specific problem with poetry when both `roman-numerals` and `roman-numerals-py` (deprecated) with version `>= 4.0.0` are in poetry.lock. 
This is likely caused by installing an older version of `sphinx` that requires `roman-numerals-py >= 1.0.0`, which downloads `roman-numerals-py 4.1.0`, which in turn requires `roman-numerals 4.1.0`.

I fixed it by removing `sphinx`, `sphinx-rtd-theme` and both `roman-numerals` packages, and reinstalling `sphinx 9.0.4` with the `sphinx-rtd-theme`. Now only `roman-numerals` appears in poetry.lock.

@AA-Turner I'm not sure whether this also happens with other package managers, unfortunately.
