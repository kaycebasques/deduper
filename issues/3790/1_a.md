Sphinx uses its own code as well as modified code from `framed.sty` for drawing "boxed" output such as code blocks, warnings, etc.
Use of the more modern package [tcolorbox](http://www.ctan.org/pkg/tcolorbox) could reduce the code size of Sphinx, make styling easier and possibly add more features (#3099, #3764). However it is not without drawbacks; since it is relatively new it may not be supported everywhere, or there may be backward-incompatible changes (#3070).
Also it uses tikz to do drawing, which can slow down compilation speed.

This issue is intended to publicly track discussion around using `tcolorbox`, which is currently spread over several comments of other issues.
