@bertini97 Chromium actually already [supports MathML](https://caniuse.com/mathml), so **all modern browsers support it now!** With the help of tools such as [latex2mathml](https://github.com/roniemartinez/latex2mathml) or [LaTeXML](https://github.com/brucemiller/LaTeXML) I guess it should be possible to implement a `sphinx.ext.mathml` extension for MathML output in Sphinx. Note that Chromium only supports [MathML Core](https://w3c.github.io/mathml-core/), a subset of MathML that should be enough for most MathML use cases.
