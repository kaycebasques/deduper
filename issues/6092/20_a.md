Thank you for the example. However, I am afraid replacing the current selection of Sphinx math-renderers with the ones provided by Docutils breaks too much existing applications and use cases to be accepted by the Sphinx developers and community.

I propose to write a new Sphinx math renderer `sphinx.ext.mathml` which imports the `docutils.utils.math.latex2mathml` module and adds the Sphinx interface.
This would open the way to use `latex2mathml`  as opt-in renderer,
"road test" the conversion, fix issues, and eventually make it the default renderer.

I can help with problems around `docutils.utils.math.latex2mathml` but have no knowledge about Sphinx extensions and their requirements.
