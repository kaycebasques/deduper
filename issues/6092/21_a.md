I'll look into importing `docutils.utils.math.latex2mathml`. However, I have the feeling that since Sphinx already uses a `HTMLTranslator` class that inherits from the docutils' `HTMLTranslator` class, that it might make more sense to access the math conversion present on that `HTMLTranslator` class, than to import it separately.
