I noticed we need to consider the way to handle container configuration values:

```
# config.yaml
extensions:
- sphinx.ext.autodoc
- sphinx.ext.autosummary
```
```
# conf.py
extensions = [
  'sphinx.ext.todo',
  'sphinx.ext.graphviz',
]
```

The `extensions` will be overridden, not merged. Is this an expected result?
