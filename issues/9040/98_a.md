Hmm, @jpmckinney quite effectively lays out (https://github.com/sphinx-doc/sphinx/issues/9040#issuecomment-855178662) the problems with both coexistence and non-coexistence. No matter what it can be quite harmful for people getting into using Sphinx.

One way forward would be to get some experience with static configuration without direct support, to see which problems users run into. I think this may already be doable with very little "magic" to be copy-pasted:
In ``conf.py`` put
```python
import myFavouriteStaticSphinxConfFormatLoader
for k, v in myFavouriteStaticSphinxConfFormatLoader.load(__file__):
   globals()[k] = v
```
where ``myFavouriteStaticSphinxConfFormatLoader`` is a third-party module (not an extension, no Sphinx entities are needed).
If it is no be distributed with the project, then a line with ``sys.path.append()`` could be added first.
