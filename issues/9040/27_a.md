If Sphinx does allow for configuration from static metadata, I would suggest using Python literals as the file format; see an example ([sphinx_static_config.zip](https://github.com/sphinx-doc/sphinx/files/6258147/sphinx_static_config.zip)) of `conf.py` below. Since this format is a subset of the Python language, everyone familiar with `conf.py` will already know to encode configuration data, rather than learning to express values in YAML/TOML/JSON/etc.

``` Python
import ast


def setup(app):
    with open("sphinx-conf.pylit", encoding="utf-8") as f:
        cfg = ast.literal_eval("{\n" + f.read() + "\n}")
    for key, value in cfg.items():
        app.config[key] = value

```
