I think words which are based on a software project should generally use the spelling that the project uses.  I haven't checked properly, but it looks like the pickle project uses picklable and unpicklable: https://docs.python.org/3/library/pickle.html#what-can-be-pickled-and-unpickled  Wiktionary has the e in: https://en.wiktionary.org/wiki/pickleable
An alternative approach is to rewrite the sentences to avoid the problem by using 'can be pickled' instead - though sometimes that can be very awkward.
