Given 2 files, 1.rst and 2.rst (between <file</file> tags.

1.rst:
<file>

```
some other title
================

TADA: :ref:`label_in_other_file`
```

</file>

2.rst:
<file>

```
.. _label_in_other_file:

some X title
============
```

</file>

That is, 2.rst has a label, linked to from 1.rst. If "some X title" in 2.rst changes, 1.rst will need to be rebuilt, since the name for its :ref: will have changed. However, this doesnt happen (using make html).
