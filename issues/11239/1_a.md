I have a Sphinx extension which reads Linux kerneldoc format comments (it's actually a fork of the Linux kernel's own extension for this). The bulk of the work is done by an external Perl script. That script has an option (-Werror) which tells it to turn its warnings into errors. I would like to be able to have my extension say "if the user passed -W to Sphinx, then pass -Werror to this script". However, I couldn't find anything in the documented APIs that Sphinx provides to extensions that indicates whether -W is in effect or not.

I did find an undocumented way to do it, which is to look at the 'warningiserror' member of the Sphinx object. This seems to be how the coverage extension does it:

https://github.com/sphinx-doc/sphinx/blob/8b7758160e878739a9a5ee33d2be41883c56706c/sphinx/ext/coverage.py#L123

This feature request is for a documented mechanism for extensions to find out whether the user passed -W to sphinx-build. I don't know whether that would be best done by simply documenting Sphinx::warningiserror as part of the API extensions can use, or whether a different way to do it already exists, or if one should be implemented.
