Subject: An incorrect smartquote is inserted when a parameter in a function doc has a table, whose entry contains a quote.

### Problem
See subject.

#### Procedure to reproduce the problem
```
sphinx-quickstart -q -pfoo -afoo
```
then paste the following into `index.rst`
```
.. py:function:: foo()

   :param foo: A table.

               ===== ===
               "foo" bar
               ===== ===
```
and build html docs.

#### Error logs / results
NA

#### Expected results
The first quote in `"foo"` is a closing quote when it should be an opening quote.
