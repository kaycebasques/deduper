There is a secondary issue that the paragraph nodes from the table cells go through *twice* through the smart quote Docutils code. 

But with this

```rst
A table.

===== ===
"foo" bar
===== ===
```

the smart quote is correctly applied. There is no problem here with "context" being the dot from ``table.``: the "context" is just a space. Besides the thing is handled once, not twice.

But if one patches docutils.utils.smartquotes to examine when the code is executed one observes that in original example it is executed **twice** which looks unintended (apart from the "context" problem).
