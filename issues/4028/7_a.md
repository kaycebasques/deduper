Note: The parameter list is converted to following doctree structure:
```
<field_list><field><field_name>Parameters</field_name><field_body><paragraph><literal_strong refspecific="True">foo</literal_strong> -- <inline translatable="True"><paragraph>A table.</paragraph><table align="default"><tgroup cols="2"><colspec colwidth="5"/><colspec colwidth="3"/><tbody><row><entry><paragraph>"foo"</paragraph></entry><entry><paragraph>bar</paragraph></entry></row></tbody></tgroup></table></inline></paragraph></field_body></field></field_list>
```

Unfortunately, this is broken.
1. `inline` node contains `paragraph` and `table` node. That's contradiction. Inline nodes can contain inline or Text node. But both are not. They're Body nodes.
2. `paragraph` node inside `field_body` node contains `table` node. This is also contradiction.

In current design, TypedField expects a description of parameter is a single paragraph. So we need to modify it to support such case.
