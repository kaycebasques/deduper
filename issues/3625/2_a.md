As a workaround, I prepared simple script named `dvipngja`. It uses dvips and imagemagick to make images.
```
$ cat dvipngja
#!/bin/sh

set -ex

while getopts o:T:z: OPT
do
    case $OPT in
      "o") OUTPUT="$OPTARG";;
    esac
done
shift `expr $OPTIND - 1`

PSFILE=`mktemp`
dvips "$1" -o "$PSFILE"
convert -trim "$PSFILE" "$OUTPUT"
rm $PSFILE
```
