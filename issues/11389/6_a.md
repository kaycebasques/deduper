cppreference uses MediaWiki for its backend, and I think [this page](https://en.cppreference.com/w/Template:c) is how their code blocks are implemented. Something interesting to note is that in

```cpp
using std::cout; // (1)
cout << x; // (2)
```

(1) forms a link to [`std::cout`'s page](https://en.cppreference.com/w/cpp/io/cout), but (2) doesn't, so parsing certainly isn't necessary. That's fine, since I'd even be happy with only the first instance of the name being the link.

```cpp
std::cout << "Hello, world!\n"; // links
std::cout << "Goodbye, world!\n"; // doesn't link
```
