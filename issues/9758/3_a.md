In my eyes, the goal of having a `locale` folder (specified with `locale_dirs` setting) is that the source of the document and the translation of the document per languages should be separated. Why should I put the localized images into to source folder while the language file can be put into the locale folder?

Please take a look at the GNOME Help pages, for example the [help file structure of gedit](https://gitlab.gnome.org/GNOME/gedit/-/tree/master/help). As you can see, the source of the documentation is in the `C` folder (images in `C/figures`) and every language has its own folder (images in `{language}/figures`).

This folder structure makes it easy to add new language or remove existing language without touching the source of the documentation and makes clear difference between the source and the translations.

The idea of using the `locale/{language}/LC_IMAGES` for localized images follows the [locale environment variables](https://www.gnu.org/software/gettext/manual/html_node/Locale-Environment-Variables.html) concept from gettext.
