### Describe the bug

Based on the documentation and the issues, tests and questions about localizing figures I cannot set the correct value for `figure_language_filename`.

### How to Reproduce

I have the following folder structure:

```
/home/me/sphinx/awesome-project/content/index.rst
/home/me/sphinx/awesome-project/content/foo/
/home/me/sphinx/awesome-project/content/foo.rst
/home/me/sphinx/awesome-project/content/foo/bar/
/home/me/sphinx/awesome-project/content/foo/bar.rst
/home/me/sphinx/awesome-project/content/foo/bar/page.rst
/home/me/sphinx/awesome-project/content/foo/bar/images/pic.png
/home/me/sphinx/awesome-project/locale/de/LC_IMAGES/content/foo/bar/images/pic.png
/home/me/sphinx/awesome-project/locale/de/LC_MESSAGES/content.po
```

The image in `page.rst` is referenced as `.. figure:: images/pic.png`

If I read the documentation correctly:

- `{root}` is mapped as `images/pic`
- `{path}` is mapped as `images/`
- `{docpath}` is mapped as `content/foo/bar/`
- `{basename}` is mapped as `page`
- `{ext}` is mapped as `.png`
- `{language}` will be `de` in my case

How can I refer to the localized image? I guess this should work, but it doesn't:

```
figure_language_filename = 'locale/{language}/LC_IMAGES/{docpath}{root}{ext}'
```

If I put the localized image in the `/home/me/sphinx/awesome-project/content/foo/bar/images/`folder named `pic.de.png` and using the default value of `figure_language_filename` then it works fine. But I would like to separate the source and the translation completely.
