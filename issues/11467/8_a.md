After some thoughts (~~totally forgot about the issue~~), I can suggest the following:

- By default, use the enumeration member itself (FQN).
- Add a configuration value containing a list of enumeration class names for which the value should be used instead. We could even allow specifying explicitly how an attribute should be documented as an enumeration value (e.g., `('my_enum', 'my.class.my_attr')` indicates that `my.class.my_attr` should be documented using the enumeration value).

We could also indicate how it should be documented at the level of the directive, though it would likely be useless since people rarely write `autoattribute` themselves. Alternatively, using a `:meta:` field would be much better and elegant.

- Add a global flag to use enumeration values instead.

With this, we could solve all issues and satisfy everyone, allowing them to display their enumeration as they want.
