Just to clarify, this should indeed produce the Enum **member**:

```py
@dataclass
class MyClass():

    colour: Colours = Colours.Green
```

If it were to be the Enum **`value`** it should instead be:

```py
@dataclass
class MyClass():

    colour: Colours = Colours.Green.value
```

> this discrepancy should either be documented or fixed (or handled differently via some configuration value)

The only Pythonic choice for this issue is **fix**, by resolving the dataclasses' attribute default value as being the Enum member (e.g. `colour: Colours = Colours.Green`).

Is intended for the specific case of documenting an `Enum` class, i.e:

```py
class Colours(Enum):

    Green = 1
```

Here the Enum members are themselves the classe's attributes and documenting them correctly requires extracting the value as is done in the snippet. The problem, it seems, is `.isenumattribute(self.object)` is being sent `Colours.Green` instead of being sent `MyClass.colour`.
