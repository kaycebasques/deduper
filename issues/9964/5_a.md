> Thanks again for the analysis, I'm going to start using `pdflatex` instead of `xelatex`. Let's see if it has any drawbacks.

The two main differences is that `xelatex` is Unicode engine, and supports usage of system fonts.

`pdflatex` has much more limited support for unicode characters (at engine level, and at font level). Most of the time one can work around it, but this requires additions to preamble. 

Also `pdflatex` produces bulkier pdf's because it does not apply the same level of font compression. This is why in my (non-Sphinx) personal usage of  `latex` and I do not use `pdflatex` but `latex+dvipdfmx` which produces sometimes spectacularly smaller pdf's.
