Let's bounce some more ideas off you. How about these two alternative features? Either of these would be nice for users I think.

1. A `:noalign:` flag that for multiple equations, switches from `aligned`/`align*` (=aligned/right-aligned) to `gather` (=centered).
2. In addition to the `:nowrap:` flag, an `:env:` flag to be used as follows:

       .. math::
           :env: gather*
   
           e^{i \pi} + 1 = 0
           \\
           x = \frac{-b\pm \sqrt{b^2-4ac}}{2a}
 
 
   or perhaps even:
 
       .. math::
           :env: aligned/align*
   
           e^{i \pi} + 1 = 0
           \\
           x = \frac{-b\pm \sqrt{b^2-4ac}}{2a}
