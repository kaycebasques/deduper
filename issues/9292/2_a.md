The regex in sphinx.util.inventory.load_v2 doesn't properly match references produced in the dump method in the same file. The code expects this regex to split the line into name, type, prio, location, dispname, but this fails:

```python
Python 3.8.5 (default, May 27 2021, 13:30:53) 
[GCC 9.3.0] on linux
import re
regex = r'(?x)(.+?)\s+(\S+)\s+(-?\d+)\s+?(\S*)\s+(.*)'
test = 'Open Energy Phase 3 std:term -1 glossary.html#term-Open-Energy-Phase-3 -'
re.match(regex, test)
<re.Match object; span=(0, 72), match='Open Energy Phase 3 std:term -1 glossary.html#ter>
re.match(regex, test.rstrip()).groups()
('Open Energy', 'Phase', '3', 'std:term', '-1 glossary.html#term-Open-Energy-Phase-3 -')
```

So the regex needs fixing to handle names more greedily.
