@tk0miya I see in the sphinx docs page that you posted it says:
```
In current release, all var, ivar and cvar are represented as “Variable”. There is no difference at all.
```
Well shouldn't there be a difference? This [stack overflow](https://stackoverflow.com/questions/64796801/documenting-class-level-variables-in-python) gives some ideas of how the user can document class variables vs. instance variables but this seems like a fundamental enough concept that it should be built into sphinx. I think the readers of our documentation would want to know whether a variable can be accessed from the class like so:
```
MyClass.class_variable
```
Or if it can only be accessed from an instance:
```
instance = MyClass()
instance.instance_variable
```
The distinction seems important and I think it could be worthwhile having this distinction automatically displayed when sphinx reads ivar or cvar.
