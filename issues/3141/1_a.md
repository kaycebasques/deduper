Sphinx doesn't seem to make a clear distinction between these two types of attributes.

The autodoc extension handles the docstrings for these two in the same way, mapping them both to `.. attribute::` directives AFAICS. There is however `:ivar:` to document instance variables. For this reason, I was under the impression that `.. attribute::` was only for class attributes. Is that assumption wrong?

The Napoleon extension neither differentiates between the two. The user only has the option to interpret **all** attributes as instance attributes by setting `napoleon_use_ivar`.
