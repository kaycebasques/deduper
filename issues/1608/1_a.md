We have a international project that we are documenting using sphinx. In the user guide, we also explain the class structure of an API. There we have a class named "Printer", which should not be offered for translation and thus be excluded in the gettext builder. We are using the word "Printer" in other context in the text, where it should be translatable. And we have this for a few places.

We propose to add syntax that allows to exclude certain words or phrases from the gettext builder. Otherwise, the translators (which might not know about this difference) could translate these parts and break the code references in the manual.
