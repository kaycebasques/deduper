When doing a `toctree` directive one can restrict the depth _below_ a certain level like this:

```
Check out the cookbook:

.. toctree::
   :maxdepth: 2

   cookbook
```

But if the `cookbook.rst` has a title like "Cookbook" as its first level (as can often be the case), it is redundant, and it would be nice to be able to omit the first level of depth. So something that allowed including only things _above_ a certain depth like this would be nice:

```
.. toctree::
   :maxdepth: 2
   :mindepth: 2
```

Does that sound like an acceptable feature to add? If so, I can try making a PR.
