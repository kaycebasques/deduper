On a doc build infrastructure for multiple projects I want to eventually release the built projects under a url .../{project}/{version}. So it would be nice to have easy access to the version number. Since users may do fancy stuff to set `version` in `conf.py`, I figure any approach to static parsing will fail and the only reliable way is to get the value from sphinx. Also parsing the built docs is not an option because I don't have control over the built sources, so don't know where the version may be in the built docs.
