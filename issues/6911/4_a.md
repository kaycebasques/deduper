A documentation generated with Sphinx generated also a so called inventory. For example, all documentation on ReadTheDocs have such inventory files. This is the target for intersphinx. If the inventory name and path is the default, you can provide `None` as a parameter to the Intersphinx configuration.

Here is a configuration from one of my projects:

```Python
# Sphinx.Ext.InterSphinx
intersphinx_mapping = {
	'python':         ('https://docs.python.org/3', None),
	'pyExceptions':   ('http://pyExceptions.readthedocs.io/en/latest', None),
	'pyMetaClasses':  ('http://pyMetaClasses.readthedocs.io/en/latest', None),
}
```

By default, you can use normal role syntax to reference objects like modules, classes, exceptions, etc.

* Role to reference a class  
   ```rest
   See :class:`FooBar` for details.
   ```
* Role to reference a exception  
   ```rest
   See :exc:`FileNotFoundError` for details.
   ```

More over, you can reference any item listed in the inventory file. So also index entries, page references, ...

If the implicit name is not unique, you can specify the intersphinx target with an extended syntax:

```rest
   See :exc:`MyException <pyExceptions:MyException>` for details.
```

To see all targets offered by an inventory, you can use:
* `sphobjinv` from https://github.com/bskinn/sphobjinv  
  See documentation: https://sphobjinv.readthedocs.io/en/latest/ ([PDF](https://readthedocs.org/projects/sphobjinv/downloads/pdf/v1.0/))

The first can also be used to generate inventory files for intersphinx, even if it's not compiled with Sphinx itself.
