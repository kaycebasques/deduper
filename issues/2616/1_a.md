There are some themes to improve footnotes on LaTeX
- numbering rule of footnotes; manually numbered footnotes and auto numbered
- scope of footnote numbers (per chapter, per section, per page and so on)
- position of footnotes defined inside admonitions
- switching footnote counter (cf. a, b, c...) in adomonitions (discussed in #2530)
- making working hyperlinked (clickable) footnotes from code captions, from inside tables, etc.
