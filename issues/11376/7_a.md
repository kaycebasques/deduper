> > WARNING: (...) target not found: optional

I tried searching in the [Google Python Style Guide](https://google.github.io/styleguide/pyguide.html) and there's no mention of using the trailing `optional` so an argument can be made that it shouldn't be used and *"not found"* is the correct action by Sphinx.

```none
Args: 
  x (T, optional):
```
