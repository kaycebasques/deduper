The "linuxdoc" Sphinx extension may be of interest. 
It defines a new directive ["flat-table"](https://return42.github.io/linuxdoc/linuxdoc-howto/table-markup.html#flat-table) that is basically an extension of ["list-table"](https://sourceforge.net/p/docutils/feature-requests/103/) with the new roles "column-span", "row-span" and automatic filling up of missing cells at the end of a row.

There is a [Docutils feature request](https://sourceforge.net/p/docutils/feature-requests/103/) intending to support these extensions in the "original" list-table directive.

Background colour does not seem to be supported.
You may try with a ["class" directive](https://docutils.sourceforge.io/docs/ref/rst/directives.html#setting-class-attributes) and custom CSS
~~~
.. list-table::

   * - *Row 1 Column 1*
     - Row 1 Column 2
     - Row 1 Column 3
        
       .. rst-class:: bg-red

     - Cell 3/4 with class value
~~~
+1 works with existing code
-1 does not work for every cell.
