If it does not work with a simple paragraph, it won't work in a list table either.
Try debugging the example with a simple paragraph.
* Check if custom CSS rules are applied at all, e.g. with a rule for all paragraphs.
* Check the generated HTML with your browsers "development tools" or look up the HTML source to see if the "rst-class" is correctly applied.
* Search the Sphinx documentation or Stackexchange for "custom CSS with Sphinx".
