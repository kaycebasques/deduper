Try to build an `autodoc` sphinx documentation for the hello world project linked below.

**Expected behavior**
Documentation generation succeds without issues.

**Your project**
https://gitlab.gnome.org/tallero/helloworld

**Environment info**
- OS: flatpak container with latest stable GNOME runtime
- Python version: the one embedded with such runtime
- Sphinx version: 3.5.4
