### Describe the bug

autodoc seems to apply automatic linking to elements inside of an annotated docstring, such as:

```rst
.. py:function:: my_workaround_function(metadata: ~sqlalchemy.sql.schema.MetaData) -> ~sqlalchemy.sql.schema.Table

   do the function thing
```


this automatic linking doesn't render correctly in HTML when one of the annotations has a `typing.Literal` to an object that doesn't have a simple repr, like an enum

### How to Reproduce

content like this:

```rst

.. py:function:: my_easy_function(metadata: ~sqlalchemy.sql.schema.MetaData) -> ~sqlalchemy.sql.schema.Table

   do the function thing

.. py:function:: my_not_working_function(metadata: ~sqlalchemy.sql.schema.MetaData, schema: ~typing.Literal[<SchemaConst.RETAIN_SCHEMA: 1>]) -> ~sqlalchemy.sql.schema.Table

   do the function thing

.. py:function:: my_workaround_function(metadata: ~sqlalchemy.sql.schema.MetaData, schema: ~typing.Literal[SchemaConst_RETAIN_SCHEMA_1]) -> ~sqlalchemy.sql.schema.Table

   do the function thing

```

the middle one doesn't render correctly:
