The thing seems to be: there is just one dir: locale_dir that is both for .po and for .mo, that means that source strings and compiled strings must be in the same dir. There is a way to circumvent this: run sphinx-intl update with  locale_dir set to build/locale and then move all .po files (renaming those files) wherever you want (for ex. in source/locale) or viceversa since building of translated docs uses .mo files only ... but this is a ugly hack...
