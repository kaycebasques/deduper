I found that the document meta data is only interpreted correctly as such when it appears in front of the title. This leads me to the situation where I have an abstract appearing in front of the title or having it not recognized.

Please take a look at my [Stack Overflow question](https://stackoverflow.com/questions/39799161/restructuredtext-abstract-appears-in-front-of-title-otherwise-not-recognized) where this is detailed with code samples and resulting output.

This might be a bug because (as quoted in the linked question) the reStructuredText documentation says:

> When a field list is the first non-comment element in a document (after the document title, if there is one), it may have its fields transformed to document bibliographic data.

So I would assume that I should be able to define the abstract below the document title.

Am I doing it wrong? Or is this something that could be improved in Sphinx?
