The arrows for the class inheritance should follow the UML definitions, therefore I propose something
like

inheritance_uml_inheritance 

The default value should be False, to not break existing usages. To get a UML conform drawing of the arrows I use the following options:

inheritance_edge_attrs = {
    'arrowsize': 1.0,
    'arrowtail': '"empty"',
    'arrowhead': '"none"',
    'dir': '"both"',
    'style': '"setlinewidth(0.5)"',
}

But it is much easier to make it in the code (line 276) and exchange the base_name and name for the UML conform drawings of the arrows to avoid the configuration used above.
