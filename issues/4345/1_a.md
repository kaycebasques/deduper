Maybe I'm missing something obvious, but it seems like napoleon unnecessarily depends on autodoc -- i.e., given a standard sphinx directive that documents an object (e.g. one written in an rst file via `.. py:class`, not inline in some code), with napoleon enabled, the docstring isn't run through napoleon.

Seems like it'd be nice to have either an explicit way of telling sphinx that one wishes to write a directive in Napoleon, or better, have all the usual ones filter through Napoleon if it's enabled.
