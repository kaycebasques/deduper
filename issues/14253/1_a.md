**Is your feature request related to a problem? Please describe.**
While Qt's included help viewer does not allow JavaScript by default, it is possible to enable it in own help viewers. This can be useful if formulas should be rendered with MathJax.

Right now the .qhp file generated does not include the .js files in the resource directories (`_static`, self.imagedir).

**Describe the solution you'd like**
I'd like a configuration option which allows to enable inclusion of .js files.

**Describe alternatives you've considered**
Right now we have an extension which modifies the .qhp file after it was written by the builder to include the missing files. Having them in there in the first place would be better IMO.
