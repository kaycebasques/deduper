**Is your feature request related to a problem? Please describe.**
Some third-party Sphinx extensions check content of generated HTML in their tests. For such extensions it would be useful if they could use `_file_checksum` which is currently in a private module `sphinx.builders.html._assets`, rather than hard-coding the hashes or calculating hashes themselves.

**Describe the solution you'd like**
Making that function part of public (stable) API, that is, removing the underscore prefix from the module name and from the function name.

**Describe alternatives you've considered**
The alternatives are:
- not testing the content at all (which reduces the code coverage);
- hardcoding the hash (which means the tests will break when a new version of Sphinx / Alabaster / etc is released);
- recalculating the hash in tests (which increases code duplication and will break when e.g. Sphinx switches to a different hash algorithm).
