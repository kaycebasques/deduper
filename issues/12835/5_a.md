I'm not sure this is a bug @dimaqq - it seems that [`object.__call__` is documented](https://docs.python.org/3/reference/datamodel.html#object.__call__) as a dunder method available to override method calls to a class instance (specifically an instance, meaning that the first argument will be populated with a reference to the instance, typically named `self` by convention).

It's OK to adjust your code to use a different pattern based on your design choices, but I don't think that this implies a bug when other components do not recognize that non-standard pattern.
