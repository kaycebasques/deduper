### Describe the bug

When the user adds an event handler for `autodoc-skip-member` what they want to know is whose member is being skipped or kept. It's impossible to know this information if `self.object` isn't available in this handler.

Right now, I have to resolve to examining the call stack and extracting this information from there. On the other hand, part of the parameters passed to this handler are worthless. For instance, the `option` parameter is already available to the user by other means (they probably defined it themselves / it's easy to get it from its static location in extension). Similarly, `objtype` is useless. One can infer that from `member`.

read bug description.

### Expected behavior

Information about where the member is defined is passed down to the handler.
