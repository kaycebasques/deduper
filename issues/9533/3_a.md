For anyone looking to use @ryandvmartin 's solution in 2026, I needed to make the following change:

```python
def maybe_skip_method(app, what, name, obj, skip, options):
    if what not in ("class", "function", "method"):
        return None
    for frame in inspect.stack():
        if frame.function == "_get_members":
            docobj = frame.frame.f_locals["obj"]
            break
```

This works on Sphinx 8.2.3 (haven't tested more broadly): it appears that there is no `"filter_members"` function in the stack anymore, and `"_get_members"` comes right after `"_skip_members"`.
