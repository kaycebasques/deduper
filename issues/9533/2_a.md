For anyone here trying to implement a custom filter on inherited methods:

```python
def maybe_skip_method(app, what, name, obj, skip, options):
    if what not in ("class", "function", "method"):
        return None
    for frame in inspect.stack():
        if frame.function == "filter_members":
            docobj = frame.frame.f_locals["self"].object
            break
```

I am sure this has issues, but as a quick solution for customizing how "autoclass" works with a global `:inherited-methods:` it seems to be okay...  In this case `docobj` is the thing being documented, and `obj` is the (possibly inherited) thing documented for `docobj`. 

With this extra context we can make custom decisions about `:inherited-methods:` - otherwise this would require customized documenters or other challenging sphinx infrastructure.
