In the above cases, I'm not changing any types, except `abs_fn`, since it is immediately converted back to a `str` with `os.fspath()` in the return statement. I assumed a round trip wasn't important to preserve.

There is no way to normalize paths using pathlib and not `normpath`:

* https://github.com/python/cpython/issues/124825

If it's important to keep the types, a helper function could be used:

```python
def normalize_path(path: Path) -> Path:
    return path.__class__(os.path.normpath(path))
```
