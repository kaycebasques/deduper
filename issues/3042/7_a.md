The problem of the word `columns` being partly hidden is a relative to original reported problem.  The `\tymin` setting was changed at some point and is set to three times the width of a character (``\setlength{\tymin}{3\fontcharwd\font`0 }``). But as `columns` does not hyphenate (contrarily to `column`), this is not wide enough (besides I believe there is here a core TeX problem).  With `column` the first column gets more squeezed but then `xquery` which does not hyphenate is partly hidden.

<img width="1278" alt="Image" src="https://github.com/user-attachments/assets/8cdce010-d6e1-437d-b88e-9177406efee8" />

Adding ``\setlength{\tymin}{6\fontcharwd\font`0 }`` to LaTeX configuration fixes that specific table.

<img width="1270" alt="Image" src="https://github.com/user-attachments/assets/cff88773-e5c4-45b1-bf30-7d5115cadfbe" />

The `tabularcolumns` directive allows to fix any such table, the problem is to become aware of the issue in the PDF in the first place.

```rest
.. tabularcolumns:: p{1.5cm}p{1cm}J
```
