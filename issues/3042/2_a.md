According to tabulary manual, user can issue in LaTeX document

```
\setlength{\tymin}{1.5cm}
```

for example to avoid narrow columns being squeezd this way. This can be inserted globally via `'preamble'` key or locally using 

``` rst
.. raw:: latex

   \begingroup\setlength{\tymin}{1.5cm}%
   \relax

<table spec>

.. raw:: latex

   \endgroup
```

See https://github.com/sphinx-doc/sphinx/issues/3043#issuecomment-253419012 for more convenient way, via specification of tabular columns.
