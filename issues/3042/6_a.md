ah wait I had forgotten that we already enlarge a bit the `\tymin` in `texinputs/sphinxmulticell.sty` (the file will be renamed for 4.x). The default of `\tymin` is `10pt`, but Sphinx does  ``\setlength{\tymin}{3\fontcharwd\font`0 }`` which means 3 times the width of zero digit in default font. This gives `15pt` as in my previous comment.

maybe we would consider increasing the `tymin` to say 6 times the width of `0`? The parameter does not take into acount the whitespace on left of right of column (between separator lines and cell contents) which is `6pt` on each side (i.e. a bit wider than the width of a letter of digit). Thus this proposal may be problematic as minimal column width is going to be about 6+2=8 letters
