### Describe the bug

autodoc-skip-member documentation states:
> autodoc-skip-member(app, what, name, obj, skip, options)
> [...]
> name – the fully qualified name of the object

https://www.sphinx-doc.org/en/master/usage/extensions/autodoc.html#event-autodoc-skip-member

It is however not what happens in practice. When checking class members, autodoc uses: [self.get_object_members](https://github.com/sphinx-doc/sphinx/blob/49bf65fc183526b13ea81fcb3aeea82ee1f80a4c/sphinx/ext/autodoc/__init__.py#L795). which in turn calls [get_class_member()](https://github.com/sphinx-doc/sphinx/blob/49bf65fc183526b13ea81fcb3aeea82ee1f80a4c/sphinx/ext/autodoc/__init__.py#L1720)

That `get_class_member()` function does not set a fully qualified member name, all you get is the member name inside the class namespace. For some objects like functions, it is possible to recover the real name but that still breaks with inheritance, as it will not be possible to know from what subclass we are being called.
