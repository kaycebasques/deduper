@nickelpro if you don't mind using a third-party extension, install [sphinxnotes.mock](https://github.com/sphinx-notes/mock) and add:

```py
if 'nohtml' in tags:
    extensions.append('sphinxnotes.mock')
    mock_directives = ['contents']
```

Then build the document with `-t` flag, e.g.  `make O='-t nohtml' latexpdf`.
