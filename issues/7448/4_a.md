A property is a kind of data-descriptors. But all data-descriptors are not properties. So `inspect.isdatadescriptor()` does not help in this case. For example, a static "public" attribute is a data-descriptor.

```
cdef class Spam:
    cdef public int attr
```
```
>>> import cyspam, inspect
>>> inspect.isdatadescriptor(cyspam.Spam.attr)
True
>>> inspect.isgetsetdescriptor(cyspam.Spam.attr)
True
```
But `Spam.attr` is not a property. So we need a marker to indicate the member is a property.
