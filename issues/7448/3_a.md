TBH I'm not even sure what make a descriptor a property, but if they are the same thing (I don't really understand [the docs](https://docs.python.org/3/howto/descriptor.html#properties)), I think we can use `inspect.isdatadescriptor`.  Additionally Cython properties also satisfy `inspect.isgetsetdescriptor`; however so are attributes of Cython extension types.  However, IIUC attributes are handled manually by Sphinx, i.e. only if we define the field, e.g.
```cython
cdef class Spam:
    """Spam.

    .. attribute:: attr

       Attribute.
    """
    cdef int attr

    @property
    def foo(self) -> int:
        """Foo."""
        return 42

    @getter
    def bar(self) -> float:
        """Bar."""
        return 6.9

    @setter
    def baz(self, value: bool) -> None:
        """Baz."""
        pass
```
