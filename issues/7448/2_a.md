Thank you for reporting. Do you know the way to detect the cython's properties?
It seems the object says it's a kind of `attribute` object:
```
<attribute 'foo' of 'cyspam.Spam' objects>
```

Note: I use following Dockerfile to get this object inspection:
```
FROM python:3.7-slim

RUN apt update; apt install -y build-essential curl unzip
RUN mkdir /autospam
WORKDIR /autospam
RUN curl -LO https://github.com/sphinx-doc/sphinx/files/4455832/autospam.zip
RUN unzip autospam.zip
RUN pip3 install cython
RUN pip3 install -e .
RUN python3 -c "from cyspam import Spam; print(Spam.foo); print(Spam.bar); print(Spam.baz)"
```
