When I have a document with several repeated links, I have "latex_show_urls = 'footnote'" in my "conf.py", the generated pdf will contain a footnote per link in the document. I would expect Sphinx to create a footnote for every DIFFERENT link only.

Example:

```
O
=

.. _X: http://example.com/

X_ X_ X_ X_ X_ X_ X_ X_ X_
X_ X_ X_ X_ X_ X_ X_ X_ X_
X_ X_ X_ X_ X_ X_ X_ X_ X_
```

"make latexpdf" will generate a document with 27 footnotes, instead of a single footnote referenced from 27 places inside the document.
