I ran into this, with this message
```
Warning, treated as error:
somefile.rst::Anonymous hyperlink mismatch: 1 references but 0 targets.
See "backrefs" attribute for IDs.
make: *** [html] Error 2
```
Without a line number I had to resort to debugging by binary-search removing content to find the error.

The mistake was this syntax error:
```rst
`link text <https://something.example/foo`__
```

A better message would be
```
somefile.rst:42:Syntax error in anonymous hyperlink: missing > character after URL.
```
