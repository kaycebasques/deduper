From the documentation of the  [:manpage:](https://www.sphinx-doc.org/en/master/usage/restructuredtext/roles.html#role-manpage) role, I infer that it serves as a reference to a *man page*, not to a command. Hence a matching the HTML representation would be a [`<cite>` element ](https://html.spec.whatwg.org/multipage/text-level-semantics.html#the-cite-element) -- a reference to a creative work by its title or name. Most browsers render `<cite>` content in italics. 

I would suggest using `<cite>` instead of `<em>` for the HTML export of the "manpage" role.

If a monospaced font is desired by an author, this may be achieved either via custom CSS or using a different *role*, e.g. :code: or :kbd: — depending on the context.
