[`:manpage:`](https://www.sphinx-doc.org/en/master/usage/restructuredtext/roles.html#role-manpage) and linked manpage with [`:manpages_url:`](https://www.sphinx-doc.org/en/master/usage/configuration.html#confval-manpages_url) should have some code/pre like style.

Currently they inherit `em` style from browser, which may be nothing or just `font-style: italic`), see:
https://docs.kernel.org/userspace-api/landlock.html

I'd say the style for `pre` would be good:

https://github.com/sphinx-doc/sphinx/blob/cc7c6f435ad37bb12264f8118c8461b230e6830c/doc/_themes/sphinx13/static/sphinx13.css#L360-L370

Or at least use the same font:
```css
font-family: 'Consolas', 'Courier New', 'DejaVu Sans Mono',
                 'Bitstream Vera Sans Mono', monospace;
```
I do not dare to send a patch as I'm not familiar with sphinx templates and jinja (I use only the default template).

To test: just use 

```
:manpage:`execve(2)`
```
And for links add to `conf.py`:
```
manpages_url = 'https://man7.org/linux/man-pages/man{section}/{page}.{section}.html'
```
