```rst
.. compound::

  paragraph starts

```

```html
<div class="compound">
<p class="compound-first">paragraph starts</p>
<div class="compound-middle math notranslate nohighlight">
\[x\]</div>
<p class="compound-last">continues</p>
</div>
```

```tex
paragraph starts
\begin{equation*}
\begin{split}x\end{split}
\end{equation*}\noindent
continues
```

Latex output seems to have a superfluous `\noindent`, and in html I'd rather hope for 

```html
<p>paragraph starts

\[x\]</span>

```
