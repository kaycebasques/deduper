Using the `autosectionlabel` extension can lead to a lot of unavoidable "duplicate label" warning messages when the same section names are used in multiple places.  For me, this comes up most often in two specific cases:

- Documents that use the same section names because they have some degree of parallel structure. For example, see the [python](https://wellmap.readthedocs.io/en/latest/basic_usage_python.html) and [R](https://wellmap.readthedocs.io/en/latest/basic_usage_r.html) tutorials for one of my projects.  
- Changelogs, which often have a bunch of "Features" or "Fixes" sections.  For example, see the [changelog](https://wellmap.readthedocs.io/en/latest/versions.html) for the same project as above, or this [stack overflow post](https://stackoverflow.com/questions/62631362/get-rid-of-duplicate-label-warning-in-sphinx).
 
I think a good way to avoid these spurious warnings would be to add the option to have `autosectionlabel` ignore certain documents and/or sections.  Specifically, what I have in mind is something like:
```
# conf.py
autosectionlabel_ignore_documents = ['changelog']
autosectionlabel_ignore_sections = ['Features', 'Fixes']
```
