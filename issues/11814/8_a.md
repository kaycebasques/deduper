>     * When rendering the glossary term, we need to know where `\myterm{foo}` was used (i.e., its page number). However, since page numbers are determined by LaTeX and not by Python, we need to use some LaTeX shenanigans. For instance, if I want to link some page, I can do `\pageref{thelabel}`. However, this requires the existence of the label itself and I don't remember whether LaTeX actually points to the text or to the top of the page.

It points to the page.  This is the general situation with backlinks from a LaTeX produced index: it lists hyperlinked page numbers, the precise locations on the pages are unknown.

There are two ways to proceed with `hyperref`:

- use `\hypertarget` and `\hyperlink`.  This by-passes filling the LaTeX `.aux` file.
- use `\label{<labelname>}` and link to it with `\hyperref[<labelname>]`.  For this to work we can have a dedicated LaTeX counter and must issue `\refstepcounter{termcounter}`, or perhaps use `\phantomsection` which is about the same under the hoods but using a specific for this general task hyperref counter.

This second approach seems to be the one more or less done by Sphinx.  For example I see this in a glossary section:

```latex
\sphinxlineitem{AM\index{AM@\spxentry{AM}|spxpagem}\phantomsection\label{\detokenize{file1:term-AM}}}
```
and at location of term use 

```latex
See also {\hyperref[\detokenize{file1:term-AM}]{\sphinxtermref{\DUrole{xref,std,std-term}{AM}}}}.
```

The first bit has the `\phantomsection  + \label` stuff I mentioned.  It also has some syntax to use LaTeX `\index` command which explains the term name will end up in `\printindex` with the page number of its definition location.
