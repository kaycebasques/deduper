I just ran into this as well with `autoattribute`. Having a re-export can break the `ModuleAnalyzer` cache:

```py
# pkg/__init__.py
from .sub import MyEnum

__all__ = ["MyEnum"]
```

```py
# pkg/sub.py
import enum

class MyEnum(enum.Enum):
    v1 = enum.auto()
    """A Docstring!"""

MyEnum.__module__ = "pkg"  # fix public package
```

When `ModuleAnalyzer` sees `MyEnum`, it stores it as `pkg.sub.MyEnum`. Then later at runtime, it encounters `MyEnum` at its export location, and doesn’t find the actual source code that includes the docstring.
