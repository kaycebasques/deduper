Please add a way to *completely turn off* everything related to index and/or search.

**Describe alternatives you've considered**
I can probably achieve this by monkey-patching (e.g. see [here](https://groups.google.com/g/sphinx-users/c/vzSAi8SM3aY)) but doing so is brittle.
