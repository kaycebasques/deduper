I obtain very satisfactory result for math in sans serif using

```
imgmath_image_format = 'svg'
imgmath_latex_preamble = r'''
\usepackage[sfdefault,scaled=.85]{FiraSans}
\usepackage[T1]{fontenc}
\usepackage[cmintegrals]{newtxsf}
'''
```

and satisfactory result for serif with

```
imgmath_image_format = 'svg'

imgmath_latex_preamble = '\\usepackage{fouriernc}'
```

Some further exploration would be needed of (serif) math packages with latex, though.

But there is a problem with inline math: the math "baseline" does not match the text one. This is related to [imgmath_use_preview](https://www.sphinx-doc.org/en/master/usage/extensions/math.html?highlight=imgmath_latex#confval-imgmath_use_preview) not being implemented for SVG output yet. We will need a patch for that, first.
