I don't think there's a lot that Sphinx can do here—it's really [quite complicated](http://stackoverflow.com/questions/11374059/make-an-html-svg-object-also-a-clickable-link). Although you could consider adding an option to the `.. image` directive that lets the user specify whether to render as an `img` or `object` tag.

In the meantime, people can write raw HTML as a workaround I guess:

```
.. raw:: html

    <object data="myfile.svg" type="image/svg+xml"></object>
```
