The feature request with docutils is something of a mash-up of support for SVG functionality.  We'll see if it remains open, as the title of the feature request focuses on SVG scaling.

For the record, here is an example of Sphinx configuration and use which produces SVG images that scale.

----

An example of how to have SVG scale dynamically to browser
window width in a document generated by Sphinx v7.1.0 with the
default "alabaster" theme:

RST requires the "image" (or "figure") directive have the option:

:width: 100 %

The Sphinx "basic" theme, the parent class of all other themes,
requires a Sphinx html_theme_option key/value pair of:

'body_max_width': 'none'

The Sphinx "alabaster" theme, the default theme, requires a
Sphinx html_theme_option key/value pair of:

'page_width': '100%'

In a Sphinx config.py file you would see something like:

```
html_theme_options = {
    'body_max_width': 'none',
    'page_width': '100%',
}
```
Although you'd expect that the html_theme_options dict might
have other key/value pairs as well.
