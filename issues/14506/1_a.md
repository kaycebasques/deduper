It looks like some other test produces the file and this test uses a "leftover" from the srcdir. A root containing the source file for this test would be `intl` instead. 
I've verified this change of roots resolves the issue for me. Although I couldn't reproduce the issue on the upstream repository, I checked the fix doesn't break anything.
