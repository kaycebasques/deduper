@picnixz just to add to the discussion:

> Feature: Have a sample page (not toc) that has a variety of reStructuredText formatting examples in it.

It's somewhat unclear what's being asked for. The best I can think of is including an optional *"Kitchen sink"* example with `sphinx-quistart`. (However, if including it as a command-line option the chances of a new user reading the docs and generating the example are slim.) Anyway, this is already solved in several places:

1. Napoleon examples
   - [Example Google Style Python Docstrings](https://www.sphinx-doc.org/en/master/usage/extensions/example_google.html#example-google)
   - [Example NumPy Style Python Docstrings](https://www.sphinx-doc.org/en/master/usage/extensions/example_numpy.html#example-numpy)

2. Most modern themes include extensive examples:
   - [Demo Documentation - RTD theme](https://sphinx-rtd-theme.readthedocs.io/en/stable/demo/structure.html)

3. The *"Kitchen sink"* examples are ubiquitous:
   - [{book}theme - Kitchen sink](https://sphinx-book-theme.readthedocs.io/en/latest/reference/kitchen-sink/index.html)   
   - [PyData - Kitchen sink](https://pydata-sphinx-theme.readthedocs.io/en/stable/examples/kitchen-sink/index.html)

5. Every part of the reST specification is written with examples:
   - The reST main page has [`statemachine.py`](https://docutils.sourceforge.io/docutils/statemachine.py)
