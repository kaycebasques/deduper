There is no standard place for the documentation of sphinxcontrib packages.

Some packages (e.g. sphinxcontrib-jsmath, sphinxcontrib-websupport) are documented in the main sphinx docs for historic reasons, but they technically don't belong there. Some use readthedocs, some just document in their README.md in the repo (e.g. https://github.com/sphinx-doc/sphinxcontrib-django).

- Do we want to have a standard / recommended location for the docs?
- Can we remove sphinxcontib docs from the main sphinx docs?
