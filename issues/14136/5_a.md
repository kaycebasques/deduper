The only thing I would note here, is that the "read phase", when directives are parsed and transforms are run (not post-transforms) are intended to be output agnostic, i.e. should not really rely on any particular builder. 
In turn, the cached environment/ast, created at the end of the read phase, can be used my multiple writers.
Strictly speaking then, if you are using the builder in directives or transforms, then you are probably doing something wrong
