### Describe the bug

Hi,

I'm using sphinx-build to format a directory full of RST files into a
directory of text files.  I have no toctree directives anywhere.  I
have added "suppress_warnings = ['toc.excluded']" to conf.py but I am
still getting "WARNING: document isn't included in any toctree" for
all of my input files.


### How to Reproduce

sphinx-quickstart -p testproject -a someauthor --sep -l en -v 0.1   /tmp/sphinx-test

echo foo > /tmp/sphinx-test/source/foo.rst
echo "suppress_warnings = ['toc.excluded']" >> /tmp/sphinx-test/source/conf.py

sphinx-build -b text /tmp/sphinx-test/source /tmp/sphinx-test/build

 At this point the warning is displayed for foo.rst.
 If you re-run this, without entirely emptying the build directory -- including dotfiles,
 you load a "pickled environment" and no longer get the warning.
 It seems that without the pickled environment you do get the warning.
 Whether or not there is pickled state should not affect the
 presence or absence of the warning.

If you'd like to better re-create my exact seup you could also:

echo bar > /tmp/sphinx-test/source/index.rst

This ensures there are no toctree directives anywhere.
