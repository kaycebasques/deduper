Ah yes, actually the `toc.excluded` does not do what you think it does. Currently, there's no way to suppress that warning (https://github.com/sphinx-doc/sphinx/pull/11677 is addressing that issue by the way).

The `toc.excluded` is for the message "toctree contains reference to excluded document" but this was actually never documented (and this should be fixed). Concerning the fact that it is pickled or not, it's because when it's already pickled and you don't have any new updated document, then the environment's consistency is not checked and the warning (which is emitted inside this check) doesn't occur. 

I'll keep the issue opened because it's a real (doc) issue.
