**Is your feature request related to a problem? Please describe.**
In some cases it'd be useful if the `extlinks`-defined roles do not generate hyperlinks at all.

For example, assume you want to generate two versions of your docs, one for internal use and another one for the general public. The internal docs should contain extlinks to an internal issue tracker/wiki/etc., whereas in the public version of the docs these links should not appear, but the captions should.

**Describe the solution you'd like**

* If the base URL is None, no link is created, but the caption is still printed (new behavior)
* If the caption is None, a link is created and the caption will be the full URL (current behavior)
* If both the base URL and the caption are None, nothing is printed (new behavior)

**Describe alternatives you've considered**
Simply removing or modifying the `extlinks` dictionary isn't enough, since (1) the link roles still need to be defined somewhere, and (2) using an empty string for the base URL will generate broken relative links. Setting the base URL to None results in an error.
