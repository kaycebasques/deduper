Since [my last comment here from 2017](https://github.com/sphinx-doc/sphinx/issues/2832#issuecomment-285893804), the situation has evolved and Sphinx users can style the tables to some extent via the configuration value [`latex_table_style`](https://www.sphinx-doc.org/en/master/usage/configuration.html#confval-latex_table_style).  It is even possible via class option or rst-class directive to style tables individually.  The default for some years for tables in PDF is to be with row colors, in that case various grays; this is despite the fact compatibility with merged cells is sub-optimal (but definitely better than with off the shelf LaTeX tools; the `tabularray` package is a relative newcomer and can not be used by Sphinx for being too recent, besides it is very much slower than the more ancient tools (`tabular`, `tabulary`, `longtable`, with `varwidth` for merged cells) used by Sphinx LaTeX.  For some more details see the [`latex_table_style`](https://www.sphinx-doc.org/en/master/usage/configuration.html#confval-latex_table_style) documentation.
