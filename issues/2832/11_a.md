Also wanted to note that you can set the text color with `\renewcommand*{\sphinxstyletheadfamily}{\leavevmode\color{white}}` for example. For this to work, you should make sure to use LuaLaTeX and load the `luacolor` package; see [this SE question](https://tex.stackexchange.com/questions/460489/using-color-in-varwidth-environment-produces-warning-and-does-not-work-as-inten).
