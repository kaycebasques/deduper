**Is your feature request related to a problem? Please describe.**

I'd like to change the default permalinks icon for documentation built with a specific theme, to `#`.

This would mean that if users do not set `html_permalinks_icon` in their `conf.py`, the documentation will build with `#` instead of `¶` as the permalinks icon.

**Describe the solution you'd like**

Honestly, not sure!

The only thing that I can think of is having something like `config.update_default_value(option, default_value)`? That would, however, be scoped as "all extensions can update any default configuration value" which can lead to race-y behaviour (the order that extensions are set up can change what default you have, if multiple extensions update the same defaults). I'm not sure that's as nice as having it be something that only themes can do -- but I'd rather trust the judgement of the maintainers here about the right thing to do for this.

**Describe alternatives you've considered**

Patching the existing Sphinx configuration object's state directly. 😅

I have a somewhat hacky solution to this, based solely on non-underscored variable names in Sphinx's configuration object. I'm not sure if this is an intended or outside-of-backwards-compatibility-policy change, so... I figured I'll flag the functionality I want in a feature request:
