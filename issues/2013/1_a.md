I would like to see a directive added to  `.. glossary::` called `:columns: #`, where a sample # would be 2.

In HTML the `<dl class="glossary docutils">` would simply need something like:
`style='-webkit-column-count: 2; -moz-column-count: 2; column-count: 2;'`.  I suggest a style over a class for the simple reason people may want their "Glossary" single column, "Acronyms" three columns and "Abbreviations" two columns.  All of these typically use `.. glossary::`.  However, putting this styling in a style class would probably be more best practice and in that case it would also be nice if the directive `:class:` functioned as well - I have not tested this and it might already work.

In LATEX `\usepackage{multicol}` would need to be added to the sphinx.sty preamble and the begin and end lines would need to be added to the outputed latex for the "glossary", with the default being 1 (shown 2 for this example):

``` latex
\chapter{Glossary}
\begin{multicols}{2}

...

\end{description}
\end{multicols}
```

If there is another way - please let me know.
