I think this is a duplicate of https://github.com/sphinx-doc/sphinx/issues/7740.
The current xref lookup in both the C++ and C domains currently only use the parent symbol as reference, not the relative position inside each declaration.
Additionally, neither domain yet makes a difference between tagged names and ordinary identifiers. For the C domain there is https://github.com/sphinx-doc/sphinx/pull/8313 which was stalled due to breakage of intersphinx lookups.
