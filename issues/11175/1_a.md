### Describe the bug

Example project location: https://github.com/hacker-cb/bug-sphinx-i18n-warnings-for-includes

I added invalid emphasis in the translation (see `locale/de/LC_MESSAGES/index.po`) 

During build:

```
make -e SPHINXOPTS="-D language='de'" html
```

I got next warnings:

```
index.rst:3:<translated>:1: WARNING: Inline emphasis start-string without end-string.
index.rst:3:<translated>:1: WARNING: Inline emphasis start-string without end-string.
```

But actually this warning are related to the `includes/test_inc.rst` file and line `3`.

So, it is very hard to find actual warnings location in big projects.




### How to Reproduce

Install

```
git clone https://github.com/hacker-cb/bug-sphinx-i18n-warnings-for-includes
cd bug-sphinx-i18n-warnings-for-includes
python3 -m venv .venv
source source .venv/bin/activate
pip install -r requirements.txt
```

Run `de` build:

```
make -e SPHINXOPTS="-D language='de'" html
```
