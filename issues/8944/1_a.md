**Is your feature request related to a problem? Please describe.**
I have a code base which uses properties (and cached properties) quite a bit, I often find myself wanting to check the source from the doc page, but currently there's no link.

I would even go further and add links for attributes in general if possible, which would be particularly handy for descriptors.
E.g. if you have a dataclass it's useful to see the source of the `Field` descriptor:
```
@dataclass
class X:
    field = Field(default_factory=lambda: 5)
```

**Describe the solution you'd like**
viewcode adds `[source]` links to class properties and attributes (possibly configurable if it's not wished by default).

**Describe alternatives you've considered**
I could probably write a plugin, I haven't looked into it yet.
