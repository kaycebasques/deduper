Autodoc generates reST document internally like below:

```
.. py:function:: render_page(pdf: pdfium.FPDF_DOCUMENT, page_index: int = 0, *, ...)
```

On generating reST document, it indeed uses `inspect` module, `ast` module, and other parsing techniques. So we will be able to get both short name and the absolute path as you said. But they will be lost on generating.
