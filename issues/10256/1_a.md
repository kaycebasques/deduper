**Is your feature request related to a problem? Please describe.**

We're using Sphinx for the [Godot Engine documentation](https://docs.godotengine.org/en/stable/) and the `gettext` module to handle localization.

We often use [substitution definitions](https://docutils.sourceforge.io/docs/ref/rst/restructuredtext.html#substitution-definitions) for `.. image::` directives, e.g. with this form:

```rst
Here comes an image:

|image0|

More paragraphs until end of page.

.. |image0| image:: img/somefile.png
```

Up until Sphinx 4.0, the gettext module would extract `|image0|`. That's already annoying because we don't want those references to be localized by translators, so they have to copy paste the `msgid` for all such references.

Since Sphinx 4.0, [the docs mention a change](https://www.sphinx-doc.org/en/master/usage/configuration.html#confval-gettext_additional_targets):

> *Changed in version 4.0:* The alt text for image is translated by default.

And indeed, we found that `|image0|` is not just a substitution identifier but it's used automatically as alt text (without the `|`s) for the image. We don't actually use this feature, but we do end up with an additional unnecessary and problematic `msgid`:

```pot
#: ../../source/index.rst:17
msgid "|image0|"
msgstr ""

#: ../../source/index.rst:28
#: ../../source/index.rst:28
msgid "image0"
msgstr ""
```

**Describe the solution you'd like**

We'd like to have an option to disable extraction of both substitution references like `|image0|` and the automatically inferred alt text for images (there might already be a configuration option for the latter not to use substitution references as alt text? I didn't spot it in the docs).

**Describe alternatives you've considered**

We could parse the generate POT files with a bash or python script to find `msgid "|(.*)|"` and use the match group to remove both `msgid "|\1|"` and `msgid "\1"`, but that sounds somewhat tedious and error prone.

**Additional context**

- Godot Engine docs: https://docs.godotengine.org/en/stable/
- Translation resource on Weblate: https://hosted.weblate.org/projects/godot-engine/godot-docs/
- Intermediate repository where Sphinx POT files are merged into a monolithic POT file for Weblate: https://github.com/godotengine/godot-docs-l10n
