**Is your feature request related to a problem? Please describe.**
I generate a web document with many sub documents. Each subdocument is also generated as docx using docxbuilder. The problem is that the figures in the subdocuments dont start at 1 since they are counted for all the pages included in sphinx.

**Describe the solution you'd like**
I'd like to be able to reset numfig counter in subparts of sphinx pages. For example : 

```rst

:numfig_reset:

.. figure:: somefigure.png
  :caption: some caption

.. toctree::
   other_file

```

The counter would be reset, so the figure in the current file would start at 1, and the files included by the toctree would follow at 2 and more.


**Describe alternatives you've considered**
Generate each document using a different sphinx run is possible as a workaround.
