**Is your feature request related to a problem? Please describe.**
Splattering the project with lots of Todo items is hardly desirable. However, it would be nice to find a list of To-Do items somewhere in the documentation, like those generated by `.. todolist::`. However, this cannot be used with enabled `.. todo::`.

**Describe the solution you'd like**
Possibly add an extra configuration option in addition to [todo_include_todos](https://www.sphinx-doc.org/en/master/usage/extensions/todo.html#confval-todo_include_todos).

**Describe alternatives you've considered**
Disabling the feature entirely.

**Additional context**
#2680 provides was solved by providing a way to hook an extension up to parse the output, but does not allow `.. todolist::` without showing `.. todo::`.
