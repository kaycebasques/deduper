**Describe the bug**
Despite its name, the `SphinxWarning` class currently does not inherit from `builtins.Warning`.
This causes issues with (for example) the likes of `warning.warn`, the latter of which can take
`Warning` instances but not arbitrary `Exception`s.

**To Reproduce**
``` python
In [1]: from sphinx.errors import SphinxWarning

In [2]: issubclass(SphinxWarning, Warning)
Out[2]: False
```

**Expected behavior**
``` python
In [3]: issubclass(SphinxWarning, Warning)
Out[3]: True
```

**Environment info**
- OS: OS independent
- Python version: Version independent
- Sphinx version: Version independent
- Sphinx extensions:  n.a.
- Extra tools: n.a.
