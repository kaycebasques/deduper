### Describe the bug

When using:

1. the autodoc extension with `autodoc_typehints = "description"`
2. `from __future__ import annotations` in a source file

a type from the ``__init__`` of a class isn't linked properly, as shown in the screenshot below, while the same type in a plain function still work as expected.

Removing the `autodoc_typehints` setting avoids the problem; however, this makes my documentation too hard to read as I have functions with many parameters and complex types.

Removing `from __future__ import annotations` also avoids the problem; however, I need it in my project. I expect Sphinx to render the same regardless of deferred evaluation of annotations.
