**Is your feature request related to a problem? Please describe.**
In a autosummary directive, the toctree directory isn't created, if the space is missing before the directory name:
`:toctree:generated`

Expected:
`:toctree: generated`

**Describe the solution you'd like**
It would be helpful to get an error message. For example, something like this:
> Error: autosummary toctree directory not created, missing space before toctree directory name

**Additional context**
In the Build your first project tutorial, on the page:
Generating comprehensive API references https://www.sphinx-doc.org/en/master/tutorial/automatic-doc-generation.html#generating-comprehensive-api-references

We add the autosummary extension:
docs/source/conf.py
```
extensions = [
   'sphinx.ext.duration',
   'sphinx.ext.doctest',
   'sphinx.ext.autodoc',
   'sphinx.ext.autosummary',
]
```

a new file:
docs/source/api.rst
```
API
===

.. autosummary::
   :toctree: generated

   lumache
```
and include the new document `api` in the root toctree:
docs/source/index.rst
```
Contents
--------

.. toctree::

   usage
   api
```

Running: `make html`
Is supposed to generate two new pages
> - api.html, corresponding to docs/source/api.rst and containing a table with the objects you included in the autosummary directive (in this case, only one).
> - generated/lumache.html, corresponding to a newly created reStructuredText file generated/lumache.rst and containing a summary of members of the module, in this case one function and one exception.

### Issue
The `generated` directory was not created.

### Cause
api.rst was typed manually, without the space before the directory name:
`:toctree:generated`

Expected:
`:toctree: generated`
