### Describe the bug

The change introduced in https://github.com/sphinx-doc/sphinx/pull/9358 to better support screen readers by adding the "heading" role to TOC captions is now leading to HTML validation errors because ``<p role="heading">`` also need to have aria-level set (e.g., HTML validator update in https://github.com/validator/validator/pull/1751 that now requires this).

I'm not quite sure what the correct aria-level is in general, that is, whether it would ever not be 1? If it's always 1 or always some other number, it would be a straightforward change.
