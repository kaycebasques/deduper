### Describe the bug

Consider the following source (taken from 1.5.0-notes.rst in NumPy):

```
:pep:`3118` compatibility
-------------------------
```

It somehow produces:
```
@node PEP 3118 compatibility,,Python 3 compatibility,Highlights<20>
@anchor{release/1 5 0-notes pep-3118-compatibility}@anchor{7f5}
@subsubsection 
@geindex Python Enhancement Proposals; PEP 3118
@strong{PEP 3118} compatibility
```
Which produces the following warning with makeinfo: 
```
numpy.texi:48587: warning: @subsubsection missing argument
```
Tested with Sphinx 4.2.0 (and sources of NumPy 1.21.6).
