Subject: Glossary terms having substitutions will not do substitutions in genindex

### Problem
What the subject says

#### Procedure to reproduce the problem
Just have a glossary rst with for example QuickBooks\ |trade| as a glossary term.  This renders correctly in the glossary page but incorrectly in the genindex page.  The genindex page shows "QuickBookstrade" instead of substituting the |trade| with the appropriate TM symbol like it does in the glossary.

### Environment info
- OS: CentOS 6
- Python version: 2.7
- Sphinx version: 1.5,5

Converting to html using 'make html'.
