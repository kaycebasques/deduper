It seems like `|trade|` is not guaranteed to be globally available. In my repro I had to include the `<isonum.txt>` [standard definition file](https://docutils.sourceforge.io/docs/ref/rst/definitions.html) from Docutils in order to make this substitution work. I tried adding the include in `rst_prolog` to make the definition more global but that did not resolve the issue in genindex.

Here are some potential resolutions to the issue:

* Update Sphinx documentation to formally define what kinds of characters and formatting are considered valid in glossary terms. In this case I think it might be fair to argue that the trademark symbol is not actually part of the glossary term. Also, Sphinx needs to generate a URL anchor based off the glossary term text. The trademark symbol is not a valid URL character, right? E.g. `https://example.com/genindex.html#term-QuickBooks™`
* When a substitution is used in a glossary term, that substitution must carry over into the genindex.
* Log a warning or error indicating that substitutions in glossary terms are not supported.
