**Is your feature request related to a problem? Please describe.**
In academic documents such as undergraduate and graduate thesis, or software focused scientific articles is common to reference the software used. For this is convenient that the software has a standard way to cite it.

Currently, sphinx does not have a standard way to cite it. Thus, each time is cited in a different, and probably incomplete way (not crediting some authors, etc).

**Describe the solution you'd like**
In Github, it is possible to add a [CITATION.cff](https://docs.github.com/es/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-citation-files) file with the necessary information. This adds an entry in the Github sidebar with the citation of the repository in both APA and Bibtex. This would be ideal to reference the project.

In addition (but that is optional) a DOI could be minted using a service such as Zenodo.

**Describe alternatives you've considered**
In the current situation, I usually use the following Bibtex:
```bibtex
@misc{sphinx_2020_sphinx,
  title = {Sphinx 4.0.0+ Documentation},
  author = {{Sphinx Development Team}},
  year = {2020},
  month = jun,
  url = {https://www.sphinx-doc.org/en/master/},
  urldate = {2020-06-16}
}
```
Some pages, such as http://citebay.com/how-to-cite/sphinx/ use a different Bibtex, but this only credit the original author, and not the whole team, and also uses an incorrect type of citation:
```bibtex
 @article{brandl2021sphinx,
  title={Sphinx documentation},
  author={Brandl, Georg},
  journal={URL http://sphinx-doc. org/sphinx. pdf},
  year={2021}
} 
```
In absence of a standard way to reference it, in some cases even references to presentations of the software from authors not involved in the project are used, which do not credit the original developers:
```bibtex
@article{lehmann2011sphinx,
  title={The Sphinx Project},
  author={Lehmann, Robert},
  journal={Universit{\"a}t Potsdam, Project Documentation},
  year={2011}
}
```
```bibtex
@article{tobar2016sphinx,
  title={Sphinx como herramienta para documentar proyectos t{\'e}cnicos},
  author={Tobar, Javier Garc{\'\i}a},
  journal={T{\'e}cnica industrial},
  volume={315},
  pages={48--52},
  year={2016}
}
```
