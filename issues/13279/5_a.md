The https://github.com/sphinx-doc/sphinx/issues/13279#issuecomment-2625331530 method will have no effect in PDF (via LaTeX) output (did not check other builders) but it can if user also defines suitably `sphinxclassnote` environment, for example like this:

```
latex_elements = {
    'preamble': r"""
\makeatletter
\newenvironment{sphinxclassnote}
  {\def\spx@noticetype{note}\begin{sphinxheavybox}}
  {\end{sphinxheavybox}}
\makeatother
""",
}
```
Unrelated note: the `\makeatletter` thing is a bit annoying (due to character `@`) and I think we should let <s>thing</s> Sphinx always use it around user "latex preamble" material as the above example.
