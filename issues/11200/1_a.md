### Describe the bug

It seems that, in Sphinx 5.3, `default_role="obj"` is not respected anymore, resulting in the entries printed literally, in cursive. See [these artifacts](https://www.psycopg.org/psycopg3/docs/api/connections.html#psycopg.Connection.pgconn) for example:

![image](https://user-images.githubusercontent.com/199429/219703929-c5407f34-8e66-447e-a594-82ace8c7cc1a.png)

This seems a regression from, at least, 5.0.

### How to Reproduce

```
git clone https://github.com/psycopg/psycopg.git
cd psycopg/docs
make env
source .venv/bin/activate
make
```


### Environment Information

```text
Sphinx == 5.3.0
furo == 2022.6.21
sphinx-autobuild >= 2021.3.14
sphinx-autodoc-typehints >= 1.12
```
