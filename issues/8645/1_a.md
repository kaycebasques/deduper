**Describe the bug**

For the following code, `A.a` won't be documented by autosummary:

```python
class A:
    "A's doc"

    a: int
    "Doc"
```

**To Reproduce**
Steps to reproduce the behavior:

1. Download [bug.tar.gz](https://github.com/sphinx-doc/sphinx/files/5761091/bug.tar.gz) and unarchive it.

2. Run `PYTHONPATH=. sphinx-build -d "./_build" docs "_build/html" -b html -W --color`


```
.                                                                                                                                                                                             
├── docs                                                                                                                                                                                      
│   ├── conf.py
│   └── index.rst
└── myproject.py
```

`myproject.py` defines class `A` as above. `index.rst` shows:

```rst
Welcome to myproject's documentation!
=====================================

.. currentmodule:: myproject

.. autosummary::
   :toctree:

   A
```

`conf.py` is minimal:

```python
project = 'myproject'
copyright = '2020, someone'
author = 'someone'
extensions = [
    'sphinx.ext.autosummary'
]
html_theme = 'alabaster'
autosummary_generate = True
```

**Expected behavior**
`A.a` being documented.

**Environment info**
- OS: Debian 10
- Python version: 3.7.3
- Sphinx version: 3.4.1
- Sphinx extensions:  autosummary
