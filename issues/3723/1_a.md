Subject: Document similar arguments, attributes at once.

### Problem
In some cases a couple of attributes or arguments happen to be similar.
A single line should suffice to document them.
That will save writing time, space in the rendered docs and improve clarity therein.

```
Attributes:
    attribute1, attribute2, attribute3 (int): This three attributes are documented at once.
```
