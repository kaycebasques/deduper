In a project I'm documenting, several classes inherit from a base class.  This base class is entirely an implementation detail, and I do not wish to document it; however, it provides a method that the child classes inherit, and I would like this method to appear in the child classes' documentation.  To make matters more complicated, I'm documenting the containing module using `automodule::` rather than listing out each `autoclass::` manually.  In this situation, there does not appear to be a combination of options that will produce the exact documentation I want.  I would thus like to request an `autoclass::` option — which can also be specified on `automodule::` — for including a given inherited method in the documentation for a class without including the documentation for anything else from the parent class.
