The mark-up

```rest
.. container:: customizedrequirement
    HELLO
    WORLD
    
    This is a formatted block
```

produces this in HTML output


```html
<div class="customizedrequirement hello world docutils container">
<p>This is a formatted block</p>
</div>
```

and as you point out it gives this in LaTeX output

```latex
\begin{sphinxuseclass}{customizedrequirement}
\begin{sphinxuseclass}{hello}
\begin{sphinxuseclass}{world}
\sphinxAtStartPar
This is a formatted block

\end{sphinxuseclass}
\end{sphinxuseclass}
\end{sphinxuseclass}
```

The feature request about `:arg1:`, etc, options is at level of reST mark-up and it is unlikely to be considered as Sphinx is multi-builder and already adding LaTeX specific directives is not very common (there is   `tabularcolumns`.  The [DocUtils container directive](https://docutils.sourceforge.io/docs/ref/rst/directives.html#container) does not make provision for options, there is only a "name" option.

The way consecutive classes are handled by LaTeX is indeed somewhat restrictive as the first named class can not know what will happen next.  It was done this way to simply maximally the LaTeX coding task of end user, each class name maps to an environment, that's it.

The lowercasing here and other modifications of the class names, and the way they end up being handed over to LaTeX does not make it a convenient information channel from reST to LaTeX.

The suggestion which comes to my mind is that you define a no-argument environment which however uses internally LaTeX control sequences with default values and holding the customization you need.  Then use "raw" latex directive.  Something like this, which is quite cumbersome as I need to add one more "container" and thus indent the source.


```rest
.. container:: setcustomization

   .. raw:: latex

      \renewcommand\SOMESTUFF{custom stuff}
      \renewcommand\SOURCE{custom source}

   .. container:: customizedrequirement

      This is a formatted block
```


with this in conf.py

```python
latex_elements = {
    'preamble': r"""
% REQUIREMENT STYLE/FORMAT
\newcommand\SOMESTUFF{---default---}
\newcommand\SOURCE{---default---}
\newcommand\ALLOCATION{---default---}
\newcommand\SAFETY{---default---}
\newenvironment{sphinxclasscustomizedrequirement}{%
	\rule{15cm}{1pt}\\ 
    \small
	\color{red}
	\MakeUppercase{\SOMESTUFF}\\
	\color{black}
	\MakeUppercase{SOURCE=\SOURCE}\\
	\MakeUppercase{Allocation=\ALLOCATION}\\
	\MakeUppercase{Safety=\SAFETY}\\
}{
\rule{15cm}{1pt}\\
}
""",
}
```
