I just stumbled upon this as well, especially seeing that the wheels do not include any license files at all.

According to https://flit.pypa.io/en/stable/pyproject_toml.html#new-style-metadata, it should just work:

```
license-files

    A list of glob patterns for license files to include. Defaults to ['COPYING*', 'LICEN[CS]E*'].
```

Doing some testing, this is indeed a tricky issue with different configurations conflicting here without a proper message. Using `flit==3.12` gave me the following results:

* Just adding `license-files` explicitly. Error:

  > flit_core.config.ConfigError: license-files cannot be used with a license table, use 'project.license' with a license expression instead

* Replacing `license.text` with `license` as well. Error:

  > flit_core.config.ConfigError: License classifiers are deprecated in favor of the license expression. Remove the 'License :: OSI Approved :: BSD License' classifier

* Removing the classifier as well includes the license files. Now we could remove the `license-files` key again, as the default behavior just works fine now.
