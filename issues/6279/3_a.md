This works for me with your patch:

```
extensions = [
    'sphinx.ext.imgmath',
]

imgmath_image_format = 'svg'

imgmath_latex = 'xelatex'

imgmath_latex_args = ['--no-pdf']

imgmath_latex_preamble = '\\usepackage{unicode-math}\\setmathfont{XITS Math}'
```

From source 
```
TEST XELATEX FOR MATH TO SVG
============================

.. math::

   x^n + y^n = z^n

.. math::

   E = mc^2

```
