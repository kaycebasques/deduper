I tried to use `xelatex --no-pdf` as latex command for handling math equations, as [dvisvgm](https://dvisvgm.de/) can convert the `.xdv` file into SVG (similarly as it does with `.dvi` file from a `latex` run).

But with

```
extensions = [
    'sphinx.ext.imgmath',
]

imgmath_image_format = 'svg'

imgmath_latex = 'xelatex'

imgmath_latex_args = ['--no-pdf']
```

I get on make html the error 

```
Exception occurred:
  File "/opt/miniconda3/lib/python3.6/shutil.py", line 120, in copyfile
    with open(src, 'rb') as fsrc:
FileNotFoundError: [Errno 2] No such file or directory: '/var/folders/4y/h4wblhdx08q0j910d0rkq3m80000gn/T/tmp356x6ljh/math.svg'
```

This is caused (surely) by the fact that `sphinx.ext.imgmath` only supports `.dvi` not `.xdv` as intermediate file extension from latex run.

But `xelatex` is useful to use OpenType Math fonts (although there are few of them). This could help for example use same fonts as MathJaX does.

Note: even after adding support for `.xdv` one should think about correct header for xelatex preamble.

**Environment info**
- OS: Mac
- Python version: 3.6.8
- Sphinx version: 2.0.0
- Sphinx extensions:  sphinx.ext.imgmath
- Extra tools: TL2019, dvisvgm 2.6.2
