Sphinx 1.0.5 incorrectly converts e.g. 

```
   Is there an equivalent of C’s "?:" ternary operator?
```

to

```
   Is there an equivalent of C’s ”?:” ternary operator?
```

(Example taken from http://docs.python.org/dev/faq/programming.html#is-there-an-equivalent-of-c-s-ternary-operator )
