I'm seeing the same issue with both HTML and PDF output, i.e. ".html" ends up enclosed with two closing double quotes. In my testing, it appears to affect quoted text starting with a period, comma, question mark, exlamation mark, colon, semicolon, close parenthesis, and space. 

Meanwhile, this is the workaround I've found:

```
#!rest
the "|dot| html" extension

.. |dot| unicode:: 0x2E
   :trim:
```
