In some (old) languages, commented lines of source files begins by a given special character (e.g. "*" or "#").
I like including description in source files and report them directly in the sphinx documentation using `literalinclude` directive using the `dedent` option. This permits to have exactly the same description in both source and doc and decrease the probability to forget doc update during dev.
However it produces some unwanted warning (i.e. `WARNING: non-whitespace stripped by dedent`) because characters commenting these line are removed (and it is expected).

For a source whose comments looks like:
```
* This is a comment line in the source file containing description to be included in the rst documentation.
```
I would appreciate to disable these "false"-warnings using one of these syntax:
```
.. literalinclude:: sourcefile
    :language: none
    :start-after: COMMENT_1_START
    :end-before: COMMENT_1_END
    :dedent-nowarning: 2 
``` 
or
```
.. literalinclude:: sourcefile
   ...
    :dedent: '* '
``` 
or any which may be more convenient for Sphinx.
