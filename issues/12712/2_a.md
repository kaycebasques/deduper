By definition what you're asking for **isn't a dedent** it's trimming (a leading comment char together with possible indentation):

> [:dedent: number (number or no value)][1]
>
> **Strip indentation characters** from the code block.

While the use case seems reasonable:

> including description in source files and report them directly in the sphinx documentation

the argument is confusing because generally you'd aim to [document code using domains][2] so the only use case I can think of is including comments in a language that doesn't have its own domain.

Doesn't the C domain have an extension that works as its own kind of autodoc?

[1]: https://www.sphinx-doc.org/en/master/usage/restructuredtext/directives.html#directive-option-code-block-dedent
[2]: https://www.sphinx-doc.org/en/master/usage/domains/index.html#built-in-domains
