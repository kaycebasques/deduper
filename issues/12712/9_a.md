I have a another use case for having non-white space part of the dedent characters.  Here is a rust example:
```
mod module {
    /// ```
    /// use package::module::factorial;
    /// assert_eq!(factorial(3), 6 );
    /// ```
    pub fn factorial(n: u64) -> u64 {
        (1..=n).product()
    }
}
```
The example above gets displayed by the rust documentation system, and tested by the rust test system,  but is not part of the code for the current file. 

I am trying to include it in related sphinx documentation using `literalinclude` . So I would like the leading spaces, the /// and the space after the /// to be removed in the text displayed to the user.
