The viewcode `[source]` link is not created for methods that are inherited, even if the source code is available.

For example, if the class structure is

```
class c1(object):
    """ doc_string for class c1 """
    def meth1(self):
        """ doc_string for method meth1 """
        return True

class c2(c1):
    """ doc_string for class c2 """
    def meth2(self):
        """ doc_string for method meth2 """
        return False
```

Then sphinx with viewcode puts a link in the `c2` documentation to the source for `c2.meth2` but no such link is created to `c2.meth1`.  The documentation for c2.meth1 is there, but the link to the source code is not. I'd like the link to show even for inherited methods.

I have looked at viewcode.py and am willing to help find a fix, but wonder if this has been looked at before, or is even possible with current analyzers.
