**Is your feature request related to a problem? Please describe.**
[sphinx.ext.napoleon](https://www.sphinx-doc.org/en/master/usage/extensions/napoleon.html#module-sphinx.ext.napoleon) allows for multiple ways to express a return type in a docstring. This works overall but, for single-line docstrings specifically, methods decorated with `@property` seem to auto-link on-build as expected.

See [ExampleClass.readonly_property](https://sphinxcontrib-napoleon.readthedocs.io/en/latest/example_google.html#example-google) for an example of a single-line docstring.

See the screenshot below:

![image](https://user-images.githubusercontent.com/10103049/218225794-31de578f-3eb6-421e-9cba-7a3e7f966dfa.png)

Only `readonly_property` includes a return type which links to `Foo`. The `do_thing` function and `get_thing` method use the same docstring format but those types don't link to `Foo` as expected.

For reference, here's the source code for the same screenshot.

```python
class Foo(object):
    """Something."""


class Bar(object):
    """My cool thing."""

    @property
    def readonly_property(self):
        """Foo: Some type."""
        return Foo()

    def get_thing(self):
        """Foo: Something."""
        return Foo()


def do_thing():
    """Foo: Something."""
    return Foo()
```

**Describe the solution you'd like**
It would be nice if the same docstring that links to `Foo` auto-links as expected, regardless of where that docstring is written. Auto-linking not just for properties but for instance/celass/static methods and functions as well.

**Describe alternatives you've considered**
Using [sphinx-autodoc-typehints](https://pypi.org/project/sphinx-autodoc-typehints) has worked as an alternative, though the rendering is a bit different than if the type is provided natively. See screenshot below.

![image](https://user-images.githubusercontent.com/10103049/218226201-a9428325-92dc-4278-b03e-c33d338ed040.png)

And the code used to generate this

```python
class Foo(object):
    """Something."""


class Bar(object):
    """My cool thing."""

    @property
    def readonly_property(self) -> Foo:
        """Some type."""
        return Foo()

    def get_thing(self) -> Foo:
        """Something."""
        return Foo()


def do_thing() -> Foo:
    """Something."""
    return Foo()
```
