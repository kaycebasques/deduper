### Problem

The HTML builder has good support for multiple separate `toctree`s with captions, like this:

```
.. toctree::
   :caption: AAA

   A1
   A2

.. toctree::
   :caption: BBB

   B1
   B2
```

In Alabaster it's rendered like this:

```
AAA

  A1
  A2

BBB
  
  B1
  B2
```

And in the RTD theme `A1` and `A2` are grouped in the table of contents:

![toctrees](https://user-images.githubusercontent.com/8181630/40123249-c90cf120-58f3-11e8-8a87-33ca65443e8e.png)

The LaTeX builder, on the other hand, gets confused when presented with the same input:

![toctrees-latex](https://user-images.githubusercontent.com/8181630/40123272-db2b05ea-58f3-11e8-9d9f-4d81483ba881.png)

#### Procedure to reproduce the problem

```bash
mkdir /tmp/sphinx-repro
cd /tmp/sphinx-repro
sphinx-quickstart --quiet --author x --project y
for i in {A,B}{1,2}; do printf "$i\n==" > "$i.rst"; done
cat > index.rst <<< '.. toctree::
   :caption: AAA

   A1
   A2

.. toctree::
   :caption: BBB

   B1
   B2
'
make latexpdf
```

#### Expected results

The table of contents should be split into two parts in LaTeX like in HTML

### Environment info
- OS: GNU/Linux
- Python version: 3.5.2
- Sphinx version: 1.7.1
