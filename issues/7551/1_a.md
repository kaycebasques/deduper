**Describe the bug**
autosummary indexes nested class wrongly.

**To Reproduce**

```
.. autosummary::
   :toctree: generated

   example.Foo
   example.Foo.Bar
```
```
# example.py
class Foo:
    class Bar:
        def meth(self): pass
```

As a result, the Bar class is indexed as `Bar (class in example.Foo)`.

**Expected behavior**
It is indexed as `Foo.Bar (class in example)` like autodoc does.
