When you reference a section title that uses math, the section title renders nicely, but references to it do not.

For example, if I make index.rst:
```
.. _ka:
  
=====================
:math:`{\rm K\alpha}`
=====================

See :ref:`ka`.
```
then building it results in the html file rendering as:
```
K𝛼 
See {\rm K\alpha}.
```
