**Describe the bug**

If a section table contains a backtick, then the automatic section label created by `autosectionlabel` also appears to have a backtick. Unfortunately, my understanding is that unfortunately interpreted text such as with the `:ref:` role [cannot have a backtick](https://stackoverflow.com/questions/66435475/how-to-escape-the-backtick-character-in-a-rst-file). So it is not possible to link to the section.

Suppose my rST document is:

```
``section``
-----------

This is my section
```

Then autosectionlabel creates the label ``` ``section`` ```

To link to this, you would have to do:
```
:ref:```section```
```

But this isn't valid syntax.

**Expected behavior**
It should be possible to use `ref` in an allowed way for every section label generated by autosectionlabel

I would have expected that autosectionlabel would slugify the section names. This would be a breaking change so it's not a good direction forward. One alternative is to remove all characters from the generated label that are invalid in a ref.

Forgive me if my understanding of how autosectionlabel works is wrong, I cannot find much documentation and had to read the source code.
