### Describe the bug

When running a parallel build using imgmath, we hit the following error probably about 10% of the time. 
Usually we can re-run our build and have it work, but this has been happening since at least Sphinx 5.3.

The full trace output is included below, it looks like it gets to `read_svg_depth` and the file exists,
but is empty. Not sure what the root cause is, but handling the case where f is empty (line is never set, just return None) should at least address the immediate error...

```python
def read_svg_depth(filename: str | os.PathLike[str]) -> int | None:
    """Read the depth from comment at last line of SVG file"""
    with open(filename, encoding='utf-8') as f:
        for line in f:  # NoQA: B007
            pass
        # Only last line is checked
        matched = depthsvgcomment_re.match(line)  # <- ERROR ON THIS LINE
        if matched:
            return int(matched.group(1))
        return None
```

Unfortunately because of the spurious nature of this, I don't have a reliable way of
reproducing it.
