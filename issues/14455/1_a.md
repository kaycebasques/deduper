**Is your feature request related to a problem? Please describe.**
docutils 0.23 has been released, and Sphinx pins on versions less than 0.23.

**Describe the solution you'd like**
Verify that Sphinx works with changes in docutils 0.23 and adjust dependency pin up to <0.24.

**Describe alternatives you've considered**
Possible to continue working with legacy version of docutils, but this poses challenges in environments that want to automatically update package versions or other packages that have dependency on docutils that aren't pinned on a legacy version.

**Additional context**
- [Release notes for docutils 0.23 release: 2026-05-27](https://docutils.sourceforge.io/RELEASE-NOTES.html#release-0-23-2026-05-27)
