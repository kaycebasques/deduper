Currently, Docutils HEAD and Docutils 0.23 are identic. Looking at a recent test result (https://github.com/sphinx-doc/sphinx/actions/runs/26420549717/job/77774235171?pr=14449), I see there is the same one failure in tests/test_search.py:147:  for all Docutils versions and no additional failure for Docutils HEAD.

OTOH, if the new configuration setting [legacy_ids](https://docutils.sourceforge.io/docs/user/config.html#legacy-ids) is set to `False`, enumerable elements (tables, figures and literal_blocks) do not have an ID. This is addressed in PR #14400.
