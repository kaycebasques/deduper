If you're using the 3rd party [`sphinx-autodoc-typehints`][1] you're generally saving yourself the trouble of writing types into docstrings to being with. There's where the problem starts: how can you be sure the error isn't being raised internally by the 3rd party extension in an intermediate step of the build process?
