> Any progress for this, or some solutions to have `Preface` in PDF (latex) output

An example of possible solution (workaround): see https://github.com/edhamma/saints:

* `index.rst` (you need to view it raw, github will hide `.. raw:: latex` sections in the preview) has `\frontmatter\bgroup` (plus some temporary setup for section numbers), before `toctree`.,
* end of `preface.rst` (last part of the frontmatter) has `\egroup\mainmatter`;
* the last chapter of mainmatter (`saints.rst`) has `\appendix` at its end.

There are, in addition, adjustments like demoting sphinx sections in frontmatter and appendix (`\part` becomes `\chapter` and so forth) so that they appear nicely in the TOC, and tweaks to the numbering, so that frontmatter it unnumbered, and appendix as the usual A, B, C, ... numbering. (The HTML output does not have this degree of sophistication, it numbers the top-level items sequentially with roman numerals, but the order is the same: https://edhamma.github.io/saints/html/index.html).
