IM(NSH)O, we shouldn't be trying to specify *what* the various TOC sections are. Just let there be more than one, with the ability to choose a numbering mangler separately for each section. If necessary, allow also specifying a free-form CSS class. The moment we start "baking in" what the sections can be, we lose flexibility, and it won't work for someone.

Some built-in manglers would be useful, but I think the mangling needs to allow the user to provide their own function. That way Sphinx isn't trying to support every possible language in which someone might want to write numbers. It also means you can provide a mangler that does things like turn "Le Début" into "Chapitre 1: Le Début"; it isn't limited to sticking *just* a "number" in front.
