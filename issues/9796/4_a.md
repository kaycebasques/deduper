For inspiration there is a similar division between topics 1 and 2 in the C and C++ domains:
1. linking to a declared entity (class, function, variable, etc.)
2. rendering arbitrary types and expressions, which happens to get hyperlinks to declared entities as usual. Similarly to how ``MyClass*`` is not a declared entity in C++ (but ``MyClass`` could be``, in Python the type ``list[int]`` is not a declared entity, but ``list`` and ``int`` are.
  In the C and C++ domains there is separat role, ``expr``, for this case, and recently'ish the info fields were changed to invoke this role internally to reuse the functionality (https://github.com/sphinx-doc/sphinx/pull/9155).
