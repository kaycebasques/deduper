>My assumption is that if a section has an explicit label added by the user then that label is already present in the app.env.domaindata['std']['labels'] dictionary at the time autosectionlabel parses that section. Please correct me if I'm wrong.

Yes and No. Sphinx goes to process documents per file.

1. Parse `file_a.rst`
1.1. Correct user-labels from the file.
1.2. Call `register_sections_as_label` for the file.
2. Parse `file_b.rst`
2.1. Correct user-labels from the file.
2.2 Call `register_sections_as_label` for the file.
...

So you can check the existence of the label in the document, and you can't do it for labels in other documents. It causes duplicated warnings if `file_a.rst` contains a section named `foobar` and `file_b.rst` contains a user-label named `foobar`.
