For HTML I am using the default sphinx theme and the default pygments theme.  I get colourful pages, and colourful highlighted code segments.

When using epub (and default themes), the pages are monochrome and the code segments are not highlighted, as well as wrapping often making it harder to read.

The FAQ mentions [wide monospaced text](https://www.sphinx-doc.org/en/master/faq.html#epub-info) but leaves the solution up to the reader to experiment with, and without giving sufficient detail on what exactly to place in which file and reference with what configuration value.

**Describe the solution you'd like**
Being able to turn on colour code highlighting for epub builder, and ideally a default or documented solution to the font width issue.  It would also be nice to have a more colourful epub theme.

Various searches do not find any solutions.  There is a site which shows the difference between default [html](https://www.florian-diesch.de/doc/sphinx/themes-and-pygments-styles/default_default/index.html) and [epub](https://www.florian-diesch.de/doc/sphinx/themes-and-pygments-styles/epub_default/index.html)
