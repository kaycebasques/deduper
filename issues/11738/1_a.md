**Is your feature request related to a problem? Please describe.**
Readers of my docu *around the world* can not be sure about when it was generated. It is because of different timezones they are in. As a workaround I do use "%Z" in "html_last_updated_fmt". But this is not user friendly because they have to do calculations related to their own timezone.

**Describe the solution you'd like**
The displayed (in HTML) time should always use the current users locale. The locale of the browser used to access the docu. Not the locale used by the machine running sphinx. I am not into webdesign but I assume some javascript is needed for this?

**Describe alternatives you've considered**
Using "%Z"
