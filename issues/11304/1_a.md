**Is your feature request related to a problem? Please describe.**
I'm trying to figure out how to also use Sphinx for Java documentation.

**Describe the solution you'd like**
At hight level it will be possible to to create Java documentation at the same way that current Python users do, for example:

```
.. testcode::

    import java.util.Arrays
    import java.util.List

    List<String> result = Arrays.asList("Python", "Java");
    System.out.println(result);

.. testoutput::

    [Python, Java]
```

Testing by `make javadoctest`

**Describe alternatives you've considered**
This is the current high level flow for Sphinx Python testing documentation process validation:
- Python:
1. Register Builder(Runs test snippets in the documentation)
2. Flow: User (create documentation) -> Sphinx Directive to Test Code -> `Builder Compile the Code` (DocTestBuilder - Compile source into a code object that can be executed by exec() or eval()) -> Sphinx Directive to Test Output

- **Proposal for Java**:

1. Register New Builder `JavaDocTestBuilder extends from DocTestBuilder` (Runs test snippets in the documentation)
2. Flow: User (create documentation) -> Sphinx Directive to Test Code -> `Builder Compile the Code` (**create** `JavaDocTestBuilder extends from DocTestBuilder`) ->  Sphinx Directive to Test Output
3. Java side will **override `compile` method** for running examples in docstrings via **Java [Shell](https://docs.oracle.com/en/java/javase/11/jshell/introduction-jshell.html)**

**Additional context**

These Java integration will be offer flavors to document Java code:
- Java native code: To test documentation for projects that consume only Java native libraries will be needed to define `conf.py` with only flavor `java`.
- Java code that consume third party libraries: In this case will be needed to define by `conf.py` a flavor with `java_with_maven`, and also define where is your maven project that contains third dependencies thru an absolute `path` (also consider option to integrate with Gradle definition).
