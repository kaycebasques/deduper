At least, it should be an extension because Sphinx core does not have a feature for python processing. At present, we have two bundled extension to do that; autodoc and autosummary. The autodoc is used to convert python object to the document simply. And autosummary is used to generate a custom document for the python object using templates. So I feel your idea is an enhancement of autosummary or new extension similar to autosummary. Sadly, I don't imagine how it will be implemented because I'm not good at the extension...
