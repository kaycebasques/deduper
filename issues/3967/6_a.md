>  If the user has a ``~/.docutils`` file enabling smartquotes, I don't think there is any way for my project to disable it. 

Since Sphinx 1.6.3, you could monkey-patch ``sphinx.util.nodes.is_smartquotable``. I tested this in `conf.py`:

```
def my_is_smartquotable(node):
    return False

def setup(app):
    import sphinx.util.nodes
    sphinx.util.nodes.is_smartquotable = my_is_smartquotable
    import sphinx.transforms
    sphinx.transforms.is_smartquotable = my_is_smartquotable
```

with success (in presence of a `smart_quotes=yes` in `docutils.conf`). Of course monkey-patching is last resort.
