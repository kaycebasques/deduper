I have good and mostly bad news. 

There is no Sphinx configuration option to have code-blocks (either globally or only in admonitions) be indented rather than framed. Hook points are lacking in the sphinxVerbatim environment to try to force-hack it, but anyhow such a change rather demands a new environment altogether.  Code-blocks can have captions either before or after so some effort will be needed to provide an alternative environment compatible with  such things, and more effort about how to proceed with continuation hints.

Somewhat good news is that you can try this:
```
latex_elements = {
    'preamble': r"""
\usepackage{changepage}
\AddToHook{env/sphinxadmonition/begin}{%
  \let\originalsphinxVerbatim\sphinxVerbatim
  \let\originalendsphinxVerbatim\endsphinxVerbatim
  \renewenvironment{sphinxVerbatim}
     {\VerbatimEnvironment
      \begin{adjustwidth}{1cm}{0pt}% add 1cm shift on left of code-blocks
      \sphinxsetup{verbatimwithframe=false}%
      \originalsphinxVerbatim}
     {\originalendsphinxVerbatim
      \end{adjustwidth}}%
}
""",
}
```

But (bad news);
- your LaTeX must not be more than about 4 or 5 years old for `\AddToHook` to exist,
- the code above will not remove the background color, this effect could be (untested) by setting this color to be same as the background color for admonition,
- the above has no effect about what happens in your edge case of a code-block inside an admonition at a page break.  These circumstances trigger a low-level TeX branch which drops using "framed" but manipulates a low-level "TeX box" and the adjustwidth environment remains without any effect then.

You did not say if you wanted this throughout document or only inside admonitions.  I think it is feasible with mid-level effort to provide the feature.  However solving the problem of preventing the top or bottom caption from being separated from the code-blocks by a pagebreak will require by itself non-trivial work, because ditching the "framed" approach also destroys the in-place existing solution to that problem.

Edit: implementing continuation hints will be very difficult.
