### Describe the bug

When using an admonition like `.. note::` with LaTeX output that contains a code block and happens to be broken over one page, the code block doesn't have a frame anymore. It doens't matter whether the code block is completely on the second page or broken up.

<img width="681" height="439" alt="Image" src="https://github.com/user-attachments/assets/ba786b7b-4cbe-4f1d-bca0-394c6a73a552" />

See also the reproducer in #13939 for a code block that's moved completely to the next page, it has no frame either. If you reduce the `\vspace` in the reproducer that it fits completely on the first page, the frame is there.

### How to Reproduce

1. Create a default page with sphinx-quickstart
2. Replace `index.rst` with the content below.
3. Run `make latexpdf`

Content:
```rst
test documentation
==================

Add your content using ``reStructuredText`` syntax. See the
`reStructuredText <https://www.sphinx-doc.org/en/master/usage/restructuredtext/index.html>`_
documentation for details.

.. raw:: latex

   \vspace{18.5cm}

Add your content using ``reStructuredText`` syntax. See the
`reStructuredText <https://www.sphinx-doc.org/en/master/usage/restructuredtext/index.html>`_
documentation for details.

.. note::

   Add your content using ``reStructuredText`` syntax. See the
   `reStructuredText <https://www.sphinx-doc.org/en/master/usage/restructuredtext/index.html>`_
   documentation for details.

   .. code:: c

      // this is a comment
      void function() {
        foo("bla");
        bar();
      }
```
