### Describe the bug

When directives are used and the `toc_object_entries` configuration is set to `False`, calling the `asdom()` method on any node containing that directive results in this exception:

```
Traceback (most recent call last):
  File "[...]/sphinx/events.py", line 96, in emit
    results.append(listener.handler(self.app, *args))
  File "repro_extension.py", line 2, in doctree_read
    doctree.asdom()
  File "[...]/docutils/nodes.py", line 1356, in asdom
    domroot.appendChild(self._dom_node(domroot))
  File "[...]/docutils/nodes.py", line 557, in _dom_node
    element.appendChild(child._dom_node(domroot))
  File "[...]/docutils/nodes.py", line 557, in _dom_node
    element.appendChild(child._dom_node(domroot))
  File "[...]/docutils/nodes.py", line 555, in _dom_node
    element.setAttribute(attribute, '%s' % value)
TypeError: not enough arguments for format string

```

### How to Reproduce

**conf.py**
```python
import sys
sys.path.append(".")

project = 'demo'
copyright = 'demo'
author = 'demo'

extensions = ["repro_extension"]

toc_object_entries = False
```

**repro_extension.py**
```python
def doctree_read(app, doctree):
    doctree.asdom()

def setup(app):
    app.connect("doctree-read", doctree_read)
```

**index.rst**
```rst
.. rst:directive:: foo

   Bar
```

### Additional context

Seems to be caused by this piece of code setting `_toc_parts` to `()`:

https://github.com/sphinx-doc/sphinx/blob/e17f39e7b535f4849754d46f2cd2e411df8aa535/sphinx/directives/__init__.py#L245-L250

...and docutils trying to convert that to a string:

https://github.com/docutils/docutils/blob/173189b4c1c095a43c9388f4edd9bf1ff5d5b49d/docutils/docutils/nodes.py#L548
