I also encountered this issue when debugging so I'd suggest creating an extension patching `docutils.nodes.Element._dom_node` as follows:

```python
def __dom_node(self, domroot):
    from docutils.nodes import serial_escape

    element = domroot.createElement(self.tagname)
    for attribute, value in self.attlist():
        if isinstance(value, (list, tuple)):  # allow list or tuple
            value = ' '.join([serial_escape('%s' % (v,)) for v in value])
        element.setAttribute(attribute, '%s' % value)
    for child in self.children:
        element.appendChild(child._dom_node(domroot))
    return element

def patch_docutils_node_to_dom_node():
    from docutils.nodes import Element

    Element._dom_node = __dom_node

def setup(app):
    patch_docutils_node_to_dom_node()
```

The issue is that Sphinx uses a tuple as an attribute value in a node. If it were a list, there would have been no issue.
