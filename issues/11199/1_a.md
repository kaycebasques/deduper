### Describe the bug

I have a project like this :

```
source
├── chap1
│   └── sect1.rst
├── chap1.rst
├── conf.py
├── figure
│   └── content.txt
└── index.rst
```

Index has a doctree that lists chap1.rst
chap1.rst inlcudes chap1/sect1.rst.

sect1.rst reference the content of a file with literalinclude like this : 

`.. literalinclude:: figure/content.txt`

It works but I get that message. Relative to chap1, I would have understood "../figure/" was needed but then it does not work.
