It would be nice if toctree had an option to produce multiple columns (for HTML output), like the hlist directive.

Example source code:

```
.. toctree::
   :columns: 2
   :maxdepth: 2

   moduleA.rst
   moduleB.rst
```

Example output before:

```
* moduleA
    * moduleA content
    * moduleA more content
* moduleB
    * moduleB content
    * moduleB more content
    * moduleB even more content
```

Example output after:

```
* moduleA                         * moduleB
* moduleA content                 * moduleB content
* moduleA more content            * moduleB more content
* moduleB even more content
```
