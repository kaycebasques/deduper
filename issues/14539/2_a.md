It does seem like the [docs](https://www.sphinx-doc.org/en/master/man/sphinx-build.html#cmdoption-sphinx-build-D) don't mention the current limitations of using dictionary values with `--define`. It appears to me that:

- Dictionary traversal is limited to one level.
- Nested lists/dictionaries are unsupported.
- Comma splitting only applies when the top-level configuration value is a list.
- `"None"` is not converted to Python `None`.

At a minimum it seems like the docs should be updated. To fix the issue it would take some design to support that.
