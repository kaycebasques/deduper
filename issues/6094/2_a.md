a workaround was proposed in SOF:

There is a way to add code to python through a package called [listings](https://en.wikibooks.org/wiki/LaTeX/Source_Code_Listings). This package allows one to show code and even complete files.

For implementing this, in `conf.py` you can add:

```
latex_elements = {
    "papersize": "letterpaper",
    "pointsize": "10pt",
    "figure_align": "htbp",
    "preamble": r"""
        \usepackage{listings}
        \lstset{ 
            language=Python,                 % the language of the code
            title=\lstname                   % show the filename of files included with \lstinputlisting; also try caption instead of title
        }
    """,
}
```
there are more settings that can be added to `lstset`.

Then the code can be added in the `.rst` file as:

```
.. raw:: latex
    
    \section{Code}
    \lstinputlisting{../../../path/to/my/file.py}
```
