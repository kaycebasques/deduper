### Describe the bug

Since Sphinx 5.0 (issue still present on the latest version - 6.1.3), using backslashes in `:code:` role requires doubling them which it didn't before. It's not mentioned in the changelog so I'm unsure if it were intentional. If it were, maybe an entry for this could be added to Sphinx 5.0's changelog.

It appears that before this, docutils's `code` role was used and the overridden version in Sphinx behaves differently with regard to backslashes.

### How to Reproduce

1. Create index.rst file:
```
.. role:: python(code)
   :language: python

:code:`D:\example\path`

:python:`r"D:\example\path"`

:code:`D:\\example\\path`

:python:`r"D:\\example\\path"`
```
2. Run commands:
```
python -m venv .venv
. .venv/bin/activate
pip install sphinx==5.0.0

echo "" > conf.py
sphinx-build -M html . _build
```
3. See the issue:
![image](https://user-images.githubusercontent.com/6032823/216186541-e3d5b401-87c7-46c1-a681-6a76ceb5f24b.png)
5. Run commands:
```
pip install 'sphinx<5'
sphinx-build -M html . _build
```
6. Compare with the previous result:
![image](https://user-images.githubusercontent.com/6032823/216186707-e4664076-08b8-4944-9419-efe08a5e7ff3.png)

If it makes it any easier, I also made a repo that you can reproduce this with:
https://github.com/Jackenmen/sphinx-issue-11172
