### Describe the bug

In Text output the `:numref:` reference to a section is not resolved correctly, but replaced with `Section %s`.

### How to Reproduce

Sample project: [numref.zip](https://github.com/sphinx-doc/sphinx/files/8102974/numref.zip)

```
$ unzip numref.zip
$ make text
```

Source:
```
$ cat content.rst 
.. _foo:

Foo
---

See :numref:`bar`


.. _bar:

Bar
---

See :ref:`foo`
```

Text output:
```
$ cat _build/text/content.txt 
1. Foo
******

See Section %s


2. Bar
******

See Foo
```





### Expected behavior

:numref: is replaced with the number of referenced section, i.e.:

```
$ cat _build/text/content.txt 
1. Foo
******

See Section 2


2. Bar
******

See Foo
```
