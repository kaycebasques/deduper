I've created an example, including both input and output files, that illustrates what I view as three major deficiencies of Sphinx formatting (I'm guessing that these issues affect not only html, but other output formats as well):

(1) The left-hand roughly 1/3 of the document is empty, wasted space.

(2) The names of modules are displayed in a small, inconspicuous font that makes it easy to miss what should be chapter headings in the document. A possible solution would be to use a much larger font and to put a horizontal line above the heading.

(3) The current format impedes navigation. This could be solved by doing the following: (a) Put an outline-format table of contents with clickable entries at the top of the document. (b) Assign consecutive integers to each module, with these numbers appearing immediately to the left of the module name (e.g., "1. Combinatorics"), both in the table of contents and in the body of the document.
