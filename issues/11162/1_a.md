### Describe the bug

When using the `.. contents::` directive on a page together with e.g. an `.. autoclass::` directive, the class methods do show up in the navigation sidebar, but they are missing from the list printed by the `.. contents::` entry. The issue probably exists on its own (that is, even when just using a `:py:method` directive).

### How to Reproduce

```rst
Page
====
.. contents::
    :local:
    :depth: 3

My Class
--------
.. autoclass:: my.Class
```

```python
class Class:
    """Test class"""

    def test_method():
        """Test method"""
```
