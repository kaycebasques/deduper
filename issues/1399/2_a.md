Here's a use-case (mine!) that you can consider as part of this enhancement. 
I have a common glossary for use across multiple documents. Sometimes I want to add one or more terms to this without editing the common glossary. Although I can add another glossary:: directive, the added terms are not part of the main (:sorted:) glossary directive. I'd like to be able to somehow include additional terms, which then are sorted along with the common set.
Attached shows better what I mean, containing two separate glossary directives, the intention being that the resulting single glossary listing shows as one combined sorted list (which it doesn't!).
