I didn't get around to update the docs for cross referencing templates, so it's somewhat misleading at the moment.
For your example I think the behaviour is correct: there is no indication that `T` in the cross reference is actually a template parameter, and that `f`/`some_class` are templates (as opposed to template specialisations).
The current implementation is a bare minimum of what I would like to work, and the following list of example highlights the limitations.

```
.. cpp:class:: template<typename T> std::vector

.. cpp:class:: template<> std::vector<bool>

.. cpp:function:: template<typename ...Args> print(std::string f, Args &&...args)

.. cpp:class:: template<typename T, std::size_t N> std::array

.. cpp:class:: template<std::size_t N> std::array<bool, N>

.. cpp:class:: template<> std::array<bool, 64>

1. Should work: :cpp:class:`template\<typename T> std::vector`
2. Should probably work, as shorthand for 1: :cpp:class:`std::vector`
3. Should probably work, as 1 but with different(?) parameter name: :cpp:class:`template\<typename U> std::vector`
4. Probably should work, as 1 but without(?) parameter name: :cpp:class:`template\<typename> std::vector`
5. Should work: :cpp:class:`template\<> std::vector\<bool>`
6. Should not work: :cpp:class:`std::vector\<T>`
7. Probably should work, as shorthand for 5: :cpp:class:`std::vector\<bool>`
8. Should work: :cpp:func:`template\<typename ...Args> print`
9. Probably should work: :cpp:func:`template\<typename ...> print`
10. Should work: :cpp:class:`template\<typename T, std::size_t N> std::array`
11. Should work: :cpp:class:`template\<std::size_t N> std::array\<bool, N>`
12. Should work: :cpp:class:`template\<> std::array\<bool, 64>`
```

I get the expected result that 2, 3, 4, 6, 7, 9 does not work, and my intention is to make all but 6 work in the future.
