Sphinx could provide an API that can be used to read reStructuredText (or other markup formats, such as MyST) as a string and return output in different formats. It is important to be able to activate some Sphinx extensions.

I guess this API could be inspired by [`docutils.core.publish_string()`](https://docutils.sourceforge.io/docs/api/publisher.html).
