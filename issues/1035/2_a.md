After thinking about this more, I want to generalize the request a bit more.  I think the right solution would be to somehow let one insert the canonical index text for an "information unit" (function, class, etc.) within an index entry (in either or both of the parent index entry and sub-entry).

I'm not sure of the right API, but to render something like this--

```
single: repr() (built-in function); __repr__() (object method)
```

I'm thinking you should be able to write something like--

```
single: :func:`repr`; :meth:`object.__repr__`
```

When creating the index entry, Sphinx would then use whatever text it automatically created for the master entry for those information units.
