### Describe the bug

`:doc:` and `:ref:` generate some bad content in recent Sphinx version (I tried `9.0.4` and `9.1.0`). See additional details below for output examples.

I also tried some older versions (`7.2.6` and `8.2.3`) and those work fine.

### How to Reproduce

Steps:
```bash
mkdir src dst

cat >./src/conf.py <<"EOF"
project = "foo"
EOF

cat >./src/index.rst <<"EOF"
A :ref:`ref <other-ref>`. A :doc:`doc <other>`
EOF

cat >./src/other.rst <<"EOF"
:orphan:

.. _other-ref:
EOF

sphinx-build -b man ./src ./dst

man ./dst/foo.1
```

### Additional context

`./dst/foo.1` contains `A ref \%<#\:other-ref>\&. A doc \%<>`, which renders as:
> A ref <#other-ref>. A doc <>

With sphinx `7.2.6` and `8.2.3` it works as expected. The generated content is `A \fI\%ref\fP\&. A \fI\%doc\fP`, which renders as:
> A <ins>ref</ins>. A <ins>doc</ins>
