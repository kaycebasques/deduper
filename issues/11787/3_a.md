I also thought one day that it would be useful if the [`only` directive](https://www.sphinx-doc.org/en/master/usage/restructuredtext/directives.html#directive-only) worked with the gettext builder.

Last time I checked, it is not possible to use the following to exclude some content from the translation:

```rst
.. only:: not gettext

   Text excluded from the translation.
```

Which feels strange given the description of the directive:

> The format and the name of the current builder (html, latex or text) are always set as a tag.

At the same time I understand that the gettext builder should ignore the `only` directive most of the time, otherwise content inside `.. only:: html` for example would not be translated. But I think it could make sense to respect it if the gettext tag is explicitely excluded.
