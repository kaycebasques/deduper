Currently these symlinks end up as duplicate files in downstream packaging

Treat the links in a special way.

```python
if os.path.islink(src):
    link_target = os.readlink(src)
    os.symlink(link_target, dst)
else:
    shutil.copy2(src, dst)
```
Might blow up if it was an absolute path in the symlink but that sounds like a bad idea anyway.
