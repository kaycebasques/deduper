### Problem

```
.. contents::
   :local:
```
Does not generate links to titles that are inside an "only" block.

#### Procedure to reproduce the problem

Content:

```
Title
=====

.. contents::
   :local:

Heading1
--------

Bla

.. only:: internal

   Heading2
   --------

   Blabala

```
