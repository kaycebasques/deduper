Sphinx does not provide a way to change the message via configuration. But it can be changed via the translation feature secretly. Could you try to put the following content as `locales/en/LC_MESSAGES/sphinx.js`, please? Then you'll see the "blah blah blah" message as a message for no search results.

```
Documentation.addTranslations({
    "locale": "en",
    "messages": {
        "Your search did not match any documents. Please make sure that all words are spelled correctly and that you've selected enough categories.": "blah blah blah",
    },
    "plural_expr": "(n != 1)"
});
```
