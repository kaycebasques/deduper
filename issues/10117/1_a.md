### Describe the bug

I tried to build an inheritance diagram using the corresponding Sphinx extension. As PNG output looks terribly unsharp, I set the graphviz output format to SVG. When rebuilding, I noticed that the graph was missing and there just was an empty field. From inspecting the generated inheritance image in `build/html/_images` with Inkscape, I could see that the graph was actually there, only that it was way too large, so there was no visible content in the small viewport filed. The actual graph was outside of the image's boundaries.

### How to Reproduce

Document a module with many inheritance nodes via `sphinx.ext.inheritance_diagram`:

```rst
.. inheritance-diagram:: path.to.module
```

with `graphviz_output_format = 'svg'` in `conf.py`

### Expected behavior

The generated graph should be visible, i. e. the actual graph content should be fitted into the image's viewport.
