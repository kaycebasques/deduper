> @tk0miya what would this be for the example above within the conf.py? `sphinx.environment.BuildEnvironment.config.YourStyle`?

@Blendify it should be a string you would use in Python's `import` statement.
Example:
- https://github.com/ansible-community/sphinx_ansible_theme/blob/a69836f/sphinx_ansible_theme/_pygments/style.py#L16 — class `AnsibleStyle` exists in the module `sphinx_ansible_theme._pygments.style`
- the "path" to use in the setting is `sphinx_ansible_theme._pygments.style.AnsibleStyle`: https://github.com/ansible-community/sphinx_ansible_theme/blob/a69836f/sphinx_ansible_theme/theme.conf#L4
- as a bonus, if you package your project as a library (Python distribution package), you could declare the same in the entry points — like https://github.com/ansible-community/sphinx_ansible_theme/blob/a69836f/setup.cfg#L62. The doc on this is here https://pygments.org/docs/plugins/. If you do this, pygments itself will autodetect your style and you'll be able to use it by that name + any tools loading pygments will have access to that style by the name as if it's bundled with pygments. See: https://github.com/ansible-community/sphinx_ansible_theme/blob/a69836f/docs/conf.py#L65.
