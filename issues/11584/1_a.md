### Describe the bug

The [documentation](https://www.sphinx-doc.org/en/master/usage/restructuredtext/directives.html#directive-option-code-block-class) for the `:class:` option of the `code-block`/`sourcecode` directive currently reads

>The class name of the graph.

Maybe it's just me but this doesn't tell me anything. What graph? What effects does setting a class name have?

Through guessing and experimentation I figured out that the classes set via this option are added to the code block's HTML `class` attribute, but it's still unclear what (if any) effect this has for other build targets, for example.

### How to Reproduce

Look at the [`code-block`/`sourcecode` `:class:` option documentation](https://www.sphinx-doc.org/en/master/usage/restructuredtext/directives.html#directive-option-code-block-class) and fail to understand it.

### Additional context

- The `:class:` option was first documented in https://github.com/sphinx-doc/sphinx/pull/10464 after it was pointed out that it was undocumented in https://github.com/sphinx-doc/sphinx/issues/10461.
- The current description saying "The class name of the graph" is also present in the [Graphviz extension docs](https://www.sphinx-doc.org/en/master/usage/extensions/graphviz.html). There it makes perfect sense, because [Graphviz graphs do have a well-defined `class` attribute](https://graphviz.org/docs/attrs/class/) and anyone who knows Graphviz will understand. So the explanation was most likely copied from there when a completely new one was warranted.
