Now Sphinx no longer control the footnote numbers by default.
* footnotes having specified numbers (ex. `[1]`): use the specified number as is.
* footnote having no specific numbers (ex. `[#]`): a footnote number is assigned by docutils per document. Sphinx simply use it.

Note: Sphinx does not uses a footnote counter on LaTeX. So this behavior might not be related with standard classes.
