There is some functionality like this in [`DefaultSubstitutions`](https://github.com/sphinx-doc/sphinx/blob/1.3.3/sphinx/transforms.py#L43-L61) already, which replaces `|version|`, `|release|`, and `|today|`.  You could modify which config variables are inlined from your `conf.py` by monkeypatching [`sphinx.transforms.default_substitutions`](https://github.com/sphinx-doc/sphinx/blob/1.3.3/sphinx/transforms.py#L36-L41).

I think the easiest way to do this would be another transform though.  Use [`Sphinx.add_transform`](http://sphinx-doc.org/extdev/appapi.html#sphinx.application.Sphinx.add_transform) to augment the document's `substitution_defs` (see standard [`SubstitutionsTransform`](http://repo.or.cz/docutils.git/blob/docutils-0.12:/docutils/transforms/references.py#l631).)

I'd be happy to review a pull request to merge this upstream.  (In which case you wouldn't need to `add_transform` it, of course, and just add it to the [`SphinxStandaloneReader`](https://github.com/sphinx-doc/sphinx/blob/master/sphinx/environment.py#L104-L106).)
