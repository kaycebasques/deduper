I extracted the comment from attached archive. To support this, we need to add `arg` role to py domain.
```
class FancyClass():
    """Some intro text.

    Args:
        arg1 (int): Argument 1. Some fancy explanation comes here.
        arg2 (int): Argument 2. See :arg:`arg1`. Args do not have
          sphinx domain.

    Attributes:
        all: Some description of `all`.
        few: See :py:attr:`all`.
        most: See :attr:`all`. Attributes have a sphinx domain!

    Methods:
        first: Returns :attr:`all`.
        second: Returns :attr:`most`. See :meth:`first`.
          While this works, linking of attribute does not.
          Neither args.
    """
```
