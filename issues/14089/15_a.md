In Matplotlib, we had to [set `autodoc_use_legacy_class_based = True`](https://github.com/matplotlib/matplotlib/pull/31020) as well. We have an internal extension that catches missing references and ignores them if in a known list. With the new implementation, [several (but not all) originating file paths](https://github.com/matplotlib/matplotlib/issues/31019#issuecomment-3788475351) were no longer recorded correctly. I have not had time to investigate further but we have set the config for now to keep our docs build working.
