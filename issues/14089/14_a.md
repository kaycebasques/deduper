I have a problem with the new autodoc implementation when writing Pydantic code. The problem vanishes when using `autodoc_use_legacy_class_based = True`.

I have narrowed it down to the following minimal reproducing example. This Bash script sets up everything (tested with Python 3.12.12 on Windows, requires uv):

```bash
mkdir repro
cd repro
cat > pyproject.toml << EOF
[build-system]
requires = ["uv_build>=0.9.17,<0.10.0"]
build-backend = "uv_build"

[project]
name = "repro"
version = "0.1.0"
requires-python = ">=3.12"
dependencies = [
    "pydantic==2.12.5",
    "sphinx==9.1.0",
]
EOF
mkdir docs
cat > docs/conf.py << EOF
extensions = ["sphinx.ext.autodoc"]
project = "repro"
EOF
touch docs/index.rst
mkdir -p src/repro/subpackage
touch src/repro/__init__.py
touch src/repro/subpackage/__init__.py
cat > src/repro/subpackage/module1.py << EOF
from pydantic import BaseModel
class Model1(BaseModel):
    member: int
EOF
cat > src/repro/subpackage/module2.py << EOF
from pydantic import BaseModel, ConfigDict
class Model2(BaseModel):
    model_config = ConfigDict(extra="allow")
EOF
uv run sphinx-apidoc -o docs src/repro  # suceeds
uv run sphinx-build -W docs docs/_build/html  # fails
```
