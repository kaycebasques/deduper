**Describe the bug**
autodoc shows undecorated signature for decorated functions

**To Reproduce**

```
def wrapper(fn):
    @functools.wraps(fn)
    def func():
        return fn(1, 2, 3)

    return func


@wrapper
def foo(x, y, z):
    return x + y + z
```
```
.. automodule:: example
   :members:
   :undoc-members:
```

This is converted to `foo(x, y, z)`.

**Expected behavior**
The function `foo` should be shown as `foo()`. That is what users see.
