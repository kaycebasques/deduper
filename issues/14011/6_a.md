I agree with @timhoffm ! reST sources should stay inside `/project/docs/source` since that's the longstanding way Python projects are organized. It's a GitHub thing that there can be a readme.rst in the main project folder, and it's notoriously difficult to fetch .rst sources from outside the `/project/docs/source` folder.

It's just a matter of textual coincide that both `readme.rst` have the same name, many projects go for `readme.md` in the project base folder.
