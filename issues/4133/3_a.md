@mwoehlke Suggestion: in your [`number_convertor`](https://github.com/mwoehlke/sphinx/commit/63891657a957456dce2906a8de20c47fab00f42f#diff-5966e6529b2c8594f9f487ac4c43a49aR35) also add a `letters` option that uses a function like:
```py
def number2letter(n):
    l = ''
    if (n > 26):
        l = chr(64 + (n - 1) / 26)
    l += chr(65 + (n - 1) % 26)
    return l
```
This gives A, B, C, etc for the first 26 chapters, followed by AA, AB, AC etc, up until ZZ for the 702nd chapter.
