Subject: ~ and . prefixes do not work when using any role

### Problem
- The `~` and `.` prefixes for references (http://www.sphinx-doc.org/en/stable/markup/inline.html#cross-referencing-syntax and http://www.sphinx-doc.org/en/stable/domains.html#cross-referencing-python-objects) do not work for the `any` role.

#### Procedure to reproduce the problem
default conf.py (just press enter throughout sphinx-quickstart)

index.rst:
```
:meth:`foo.bar` is foo.

:meth:`~foo.bar` is foo.

:meth:`.bar` is foo.

:meth:`~.bar` is foo.

:any:`foo.bar` is foo.

:any:`~foo.bar` is foo.

:any:`.bar` is foo.

:any:`~.bar` is foo.

.. py:method:: foo.bar
```

#### Error logs / results
Warnings in the build:
```
/tmp/foo/index.rst:11: WARNING: 'any' reference target not found: ~foo.bar
/tmp/foo/index.rst:13: WARNING: 'any' reference target not found: .bar
/tmp/foo/index.rst:15: WARNING: 'any' reference target not found: ~.bar
```

Rendered result:
```
foo.bar() is foo.

bar() is foo.

bar() is foo.

bar() is foo.

foo.bar is foo.

~foo.bar is foo.

.bar is foo.

~.bar is foo.
```

#### Expected results
Last three entries should also be rendered as `bar` and reference `foo.bar()`.

### Environment info
- OS: Arch Linux
- Python version: 3.6.0
- Sphinx version: 1.5.5
