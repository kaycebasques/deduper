**Is your feature request related to a problem? Please describe.**

Sphinx requires putting `.po` files in `locales/LANG/LC_MESSAGES/*.po`. This path is long and inconvenient. (Currently, I am using symlinks to alleviate this.)

**Describe the solution you'd like**

Sphinx allows loading PO files from directories not following this scheme. It might want the MO files in a directory named like this for the sake of `gettext`, but it could build the MO files in a different directory than the origin directory of the PO files, like somewhere in the build directory. Actually, this would also eliminate the annoyance that MO files clutter the source directory.
