### Describe the bug

When we define a target in the Python domain, e.g.

`.. py:type:: .MyAlias`

for an object `foo.bar.MyAlias`, this appears to work (although is not documented?) in that it does hide module path, cross-references to `MyAlias` properly resolve, however the `.` itself appears. It would guess this is not intended.

Here is an example from pandas.

<img width="243" height="78" alt="Image" src="https://github.com/user-attachments/assets/0c04cd50-50e3-40fc-bcfc-2eb9bb156462" />

### How to Reproduce

`foo/bar.py`

```python
from typing import TypeAlias

MyAlias: TypeAlias = str | int
```

`index.rst`

```rst
.. py:type:: .MyAlias
```
