Internally, `Example2` class is converted to the following reST mark-up:
```
.. py:class:: Example2(param1: test.OtherClass, param2: test.MyEnum = <MyEnum.FIRST: 1>)
   :module: test

   When an enum is assigned a default value no type links are resolved


   .. py:method:: Example2.foo(param1: test.OtherClass, param2: test.MyEnum = <MyEnum.FIRST: 1>)
      :module: test
```

The enum objects are converted to repr-styled string `<MyEnum ...>`. But it is not a valid python signature. So Sphinx failed to parse it on latter step to make them hyper-linked.
