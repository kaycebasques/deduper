### Describe the bug

Blank lines are a normal part of code<s>. Test `node.rawsource.startswith('>>>')` fails to make blank lines `pythonconsole`</s>:

![image](https://user-images.githubusercontent.com/11288701/211186830-d62c64cf-a4d5-450c-bcd6-0aa486b3f8b3.png)

copy/paste from sphinx to python console causes a severe error:
```py
>>> for i in (1,2):
...   print(i)
...
1
2
>>> >>>
  File "<stdin>", line 1
    >>>
    ^^
SyntaxError: invalid syntax
>>> # Blank line above
```

### How to Reproduce

Build the following file:

*index.rst*

```py
>>> for i in (1,2):
...   print(i)
...
>>>
>>> # Blank line above
```
