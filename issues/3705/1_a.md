Source:
```rst
.. topic:: This is a topic

   .. figure:: more.png
      :name: afigure

      This is the caption.

      This is some legend.

Now the link to the figure: :ref:`does not work <afigure>`.
```

This is due to the fact that `visit_figure()`  in [latex writer](https://github.com/sphinx-doc/sphinx/blob/stable/sphinx/writers/latex.py) does not insert the `\label` (``ids``) in case the ``elif self.in_minipage:`` branch is taken.

Further, there should be a ``\capstart`` so that the link points to start of image. But this needs something like this
```
\makeatletter\def\@captype{figure}\makeatother
\capstart
```
if really  a `center` environment is used.

### Environment info
- Sphinx version: 1.5.5
