Case in point.   Sphinx creates HTML anchors with mixed case letters. Example:

- http://hub.senzing.com/g2-sdk-python-next/senzing.html#senzing.g2product.G2Product.license

But documentation that tries to reference the anchor, such as
```
        A convenience method for
        :ref:`license<senzing.g2product.G2Product.license>`.
```    
Gets this error:    
```
/home/senzing/senzing.git/g2-sdk-python-next/src/senzing/g2product.py:docstring of senzing.g2product_abstract.G2ProductAbstract.license_as_dict:1: WARNING: undefined label: 'senzing.g2product.g2product.license'
```
