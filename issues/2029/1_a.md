I have greatly appreciated the improvements in `code-block` and `literalinclude`. I think there is still a functionality that would be nice to add.

I think that it should be given an option to strip out lines containing a given string, pretty much the `:start-after` option does. It would allow for instance to remove special comments we do not want to enter the docs. 

My use case is the following: I extract code snippet form an example and some are nested in others, as

```
#snippet 1 begins
...
#snippet 2 begins
...
#snippet 2 ends
...
#snippet 1 ends
```

Ideally I would like to show snippet 2 to explain something specific, and then snippet 1 for the whole code. I think relying on code line is a fragile approach.
