### Describe the bug

The `toc-tree` directive with the `:glob:` option warns about no matches being there even if the whole statement is excluded from the build using the `.. only:` directive. 

### How to Reproduce

```
sphinx-quickstart minimal_example
cd minimal_example
```

index.rst:

```
.. minimal_glob_only_example documentation master file, created by
   sphinx-quickstart on Fri Nov 24 12:16:13 2023.
   You can adapt this file completely to your liking, but it should at least
   contain the root `toctree` directive.

Welcome to minimal_glob_only_example's documentation!
=====================================================

.. only:: non_existent_tag

   IF

   .. toctree::
      :glob:

       foo/*

.. only:: not non_existent_tag

   ELSE
```

Then run `make html`, there is a warning:

```
/home/mnoethe/Projects/sphinx_minimal/index.rst:13: WARNING: toctree glob pattern ' foo/*' didn't match any documents
```

Although the content is excluded with the only tag
