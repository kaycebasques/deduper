This also makes it impossible to have separate TOCs for different targets without having to edit `index.rst` depending on the build target.

My use case is to have multiple TOCs for HTML output, each representing a part (as in the level above chapters) with an item (rst file) for each chapter, while having a separate TOC for LaTeX output where each part is represented by a rst file that includes each chapter with an "include" directive. These rst files are not in HTML builds as that would lead very large pages (containing all the chapters of a part).
