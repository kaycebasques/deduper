I reduced this to three files with no third-party extensions.

**`conf.py`**

```python
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).parent.resolve()))

extensions = [
    "sphinx.ext.autodoc",
    "sphinx.ext.autosummary",
]
```

**`bug.py`**

```python
import dataclasses


@dataclasses.dataclass(frozen=True, order=True, slots=True, unsafe_hash=True)
class Feather:
    items: list
    denominator: int
    numerator: int
    exponent: float = dataclasses.field(default=0.625, kw_only=True)
```

**`index.rst`**

```rst
Sphinx issue 13410
==================

.. currentmodule:: bug

.. autosummary::
   :nosignatures:

   ~Feather

.. autoclass:: Feather
```

Run with Python 3.13:

```console
sphinx-build -E -W -b dummy . _build
```

Results:

- Sphinx 8.1.3: succeeds
- Sphinx 8.2.0 and 8.2.3: emit:

```text
index.rst:10:<autosummary>:1: WARNING: Inline emphasis start-string without end-string. [docutils]
```

Removing either `kw_only=True` or the `autoclass` directive makes the Sphinx 8.2.3 build succeed. The `autoclass` directive appears to be the missing element from the earlier reproduction attempt.
