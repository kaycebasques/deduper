### Describe the bug

This works in Sphinx up to (and including) 8.1.3:
```
@dataclasses.dataclass(frozen=True, order=True, slots=True, unsafe_hash=True)
class Feather:
    items: list
    denominator: int
    numerator: int
    exponent: float = dataclasses.field(default=0.625, kw_only=True)
```
But this same code now causes Sphinx 8.2.0 autosummary to complain:
```
...foo.rst:43:<autosummary>:1: WARNING: Inline emphasis start-string without end-string. [docutils]
```
8.2.0 is happy when `kw_only=True` is removed; ie, this generates no warnings under 8.2.0:
```
@dataclasses.dataclass(frozen=True, order=True, slots=True, unsafe_hash=True)
class Feather:
    items: list
    denominator: int
    numerator: int
    exponent: float = dataclasses.field(default=0.625)
```
Presumably something changed from 8.1.3 to 8.2.0 in the way that autosummary parses dataclass signatures.

Tested under 8.2.0, 8.2.1, 8.2.2 and 8.2.3: all four releases generate the same warning.

### How to Reproduce

Run autosummary on this under 8.2.0, 8.2.1, 8.2.2 or 8.2.3:
```
@dataclasses.dataclass(frozen=True, order=True, slots=True, unsafe_hash=True)
class Feather:
    items: list
    denominator: int
    numerator: int
    exponent: float = dataclasses.field(default=0.625, kw_only=True)
```
The following warning will appear:
```
...foo.rst:43:<autosummary>:1: WARNING: Inline emphasis start-string without end-string. [docutils]
```
The warning did not appear under 8.1.3 (and earlier).
