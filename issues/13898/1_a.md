**Is your feature request related to a problem? Please describe.**
Our documentation links to several external sites that unfortunately will frequently return 500-series errors, sometimes for hours at a time. 

**Describe the solution you'd like**
I'd like to be able to add something like the following to `conf.py`:

```python
linkcheck_allow_server_error = True
```

that then treats 500-series HTTP status codes as success.

**Describe alternatives you've considered**
- Disable linkcheck (we don't want to do this if we can avoid it)
- Disable linkcheck in CI (again... we'd rather avoid it)
- Add these sites to `linkcheck_ignore` (we'd like to be notified if we get 404s or similar)
