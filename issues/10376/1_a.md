The current Latex output is

1. a title page which can be customized by Latex code,

2. the table of contents, which may be customized by Latex code,

3. the document contents.

There is currently no easy way to place content between 1. and 2. It can be done through the custom Latex code for the table of contents, however, there seems to be no way to add content defined through reStructuredText. Use cases for content between 1. and 2. are:

* distribution, license, copyright, confidentiality, export control statements

* document change logs or document revision information

I would like to propose a new directive for this place in the document: `prologue`. If such an addition is acceptable, I could work on it, but with a low priority.
