Python 3.11 adds support for [PEP 646 Variadic Generics](https://peps.python.org/pep-0646/). This allows one to annotate the type of a function argument using `Unpack` or _star expression_, like below:

```python
import typing

Ts = typing.TypeVarTuple('Ts')

def f(x: tuple[typing.Unpack[Ts]]):  # annotate using Unpack
    pass

def g(x: tuple[*Ts]):  # annotate using star expression
    pass
```

However, Sphinx (5.3.0, the latest release) only supports the `Unpack` syntax but not the star syntax. That is, the following reStructuredText snippet builds without problem:
```rst
.. function:: f(x: typing.Tuple[typing.Unpack[Ts]])
```

but the following snippet builds with a warning message `WARNING: could not parse arglist ('x: typing.Tuple[*Ts]'): Unable to parse Starred object`:
```rest
.. function:: g(x: typing.Tuple[*Ts])
```

In the latter case, the generated output displays the annotation as is, without for example resolving `typing.Tuple` to the proper link as Sphinx normally would.

It would be great to add support for star expression in variadic generics type annotation. Thank you!
