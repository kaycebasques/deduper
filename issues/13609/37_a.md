> What is the Sphinx LaTeX writer output for
> 
> ```
> .. note::
>    :name: my-note
>    
>    This is an admonition with ID
>    
> Link to my-note_. 
> ```
> 
> ? (The Docutils LaTeX writer fails on this one, cf. [Docutils bug #503](https://sourceforge.net/p/docutils/bugs/503/).)

Inserting this source at the end of the reST of my previous comment and activating Sphinx LaTeX using my patch from the end of https://github.com/sphinx-doc/sphinx/issues/13609#issuecomment-2937087733 on top of Sphinx at 2b7e3adf2, Docutils r10153, and Python 3.13, I get the following LaTeX:

```latex
\begin{sphinxadmonition}{note}{Note:}
\sphinxAtStartPar
This is an admonition with ID
\end{sphinxadmonition}

\sphinxAtStartPar
Link to {\hyperref[\detokenize{index:my-note}]{\sphinxcrossref{my\sphinxhyphen{}note}}}.
```

and the following rendering in PDF:

<img width="1291" alt="Image" src="https://github.com/user-attachments/assets/0e4237d6-7008-4743-be3b-2b0c1541b745" />

The hyperlinking has failed here because there is no label `index:my-note` in the produced LaTeX.

Seeing this I try now removing my patch so with genuine Sphinx 2b7e3adf2 and.... well I obtain the same non-hyperlinked result.  The output LaTeX is the same.

*the source file is called `index.rst` hence `index` used as prefix in the labels*
