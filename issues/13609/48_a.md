> Are there still parts of `docutils.writers.latex2e` that are used in Sphinx?

As far as I know, little of it.  We import `Babel` in sphinx.builders.latex.util. Probably sphinx.writers.latex keeps a general achitecture close to what Docutils does, after all we all have to deal with visiting and departing nodes. About explicit usage of some Docutils original mark-up I only find
```
    def visit_line_block(self, node: Element) -> None:
        if isinstance(node.parent, nodes.line_block):
            self.body.append(r'\item[]' + CR)
            self.body.append(r'\begin{DUlineblock}{\DUlineblockindent}' + CR)
        else:
            self.body.append(CR + r'\begin{DUlineblock}{0em}' + CR)
        if self.table:
            self.table.has_problematic = True

    def depart_line_block(self, node: Element) -> None:
        self.body.append(r'\end{DUlineblock}' + CR)
```
as well as emitting `\DUrole` in `visit_inline()`.  Those LaTeX macros definition are to be found near bottom of `texinputs/sphinxlatexobjects.sty` in a section starting with the comment
```
%% FROM DOCTUTILS LATEX WRITER
%
% The following is stuff copied from docutils' latex writer.
%
```

That file `texinputs/sphinxlatexobjects.sty` contents is probably the one for which the LaTeX code remained almost un-modified here at Sphinx for a very long time, but the `fulllineitems` environment for object descriptions finally received significant add-ons over the recent years.  I don't know if it originated in Docutils LaTeX or some derivative.

For a long time since I started contributing to Sphinx around 2016 I was mainly busy with the LaTeX macro code support.  In those years @tk0miya contributed the major changes to the builder and writer Python code.  Among these contributions, the footnote transform and the Table class to help into supporting merged cells in tables.  The pure LaTeX code aspect associated with either of them is non trivial, the first one (footnotes) being a transfer of a LaTeX package I distributed elsewhere to work around problems with `hyperref` the (20+ years old) `footnote` package had, which I discovered here at Sphinx, the second one (about tables) working around various bugs/defects/incompatibilities of upstream LaTeX such as `\multirow`, `\multicolumn` etc...
