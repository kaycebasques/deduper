> a) skip adding labelds for a target with "refid", if the next node is an instance of nodes.image, nodes.figure, nodes.topic, ...

We currently have

```
HYPERLINK_SUPPORT_NODES = (
    nodes.figure,
    nodes.literal_block,
    nodes.table,
    nodes.section,
    captioned_literal_block,
)
```
This does not include for example admonitions because admonitions are not native to LaTeX and it is all decided by how we implement them.  We can add needed code but it will not always be easy to not have an impact on vertical whitespace due to LaTeX upstream defects, especially if in a table cell.  Note that for example even in base LaTeX for figures or tables having a notion of captions extra package is needed such as `hypcap` so that target will be on top of element and not underneath the caption.  Not all displayed elements are natively "target-able" in LaTeX, for example an equation needs to be numbered, an image needs to have a caption, same for a table.  However we can at Sphinx render almost anything somewhat easily "target-able" because to start with every paragraph start with `\sphinxAtStartPar` so for example it would be enough for a cheap solution for the LaTeX writer to insert a command which would set a toggle, `\sphinxAtStartPar` would test the toggle and if needed create a target with a given label, and the unset the toggle.  In this way it is easy with almost no discrimination to tell output "as soon as a paragraph is start next, put there a target for that label". The only things not starting paragraphs are basically equations but this is already taken care of.
