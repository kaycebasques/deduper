The `<paragraph>` example works in Sphinx because the current implementation checks for `<target refid="...">` followed by an element with `refid in ids` (i.e. targets whose ID was moved by the `PropagateTargets` transform.

> Do you have in sight some changes at Docutils which would require us to adapt here? 

I actually considered removing the `<target>` elements without ID (but decided to keep them because they may help a future "reStructuredText" writer.) Currently, "spent" `<targets>` are removed from places where they are invalid (e.g. as second element in a figure (between image and caption)).

However, relying on `<target refid="...">`  fails for IDs set via the common directive option "[name](https://docutils.sourceforge.io/docs/ref/rst/directives.html#name)":
Elements of type image, figure, topic, sidebar,  math_block, literal_block, rubric, block_quote, compound, container, table, admonition, attention, caution, danger, error, hint, important, note, tip, or warning may have IDs set either via a preceding hyperref target or via the "name" option.

To handle IDs set via the "name" directive option in the Sphinx LaTeX writer, there are 3 alternatives:

a) skip adding labelds for a target with "refid", if the next node is an instance of nodes.image, nodes.figure, nodes.topic, ...
b) when handling IDs of images, figures, topics, ..., check for every ID if a label for this ID is already added via the "refid" of a preceding target.
c) stop adding labels for `<target refid="...">` . Add labels for all (or almost all) elements with non-empty "ids" attribute.

Variant c) seems to me the most clean. The upcoming Docutils 0.23.dev LaTeX writer will implement it with a "visitor hook" in writers.latex2e.LaTeXTranslator:
~~~python
    def dispatch_visit(self, node) -> None:
        """
        Actions to take before calling the node visiting function.

        Handle IDs for (almost) all Body nodes, sidebar, and topic
        (see `self.ids_to_labels()`).
        TODO: Add Body Subelements.

        Provisional. Requires more testing.
        """
        # self.visit_node_hook()

        # Set anchor with \phantomsection and \label for elements with IDs
        # nodes to prepend with anchor and labels:
        id_nodes = (nodes.Body,  # see below for exceptions
                    nodes.sidebar,
                    # nodes.Inline,  # handled by visit_inline()
                    )
        # nodes that use their own ID handling (see visit_*()):
        id_exceptions = (nodes.citation,        # backlink (\hyperref)
                         nodes.footnote,        # backlink (\hyperref)
                         nodes.image,           # move behind \href eventually
                         nodes.math_block,      # label inside environment
                         nodes.paragraph,       # handled by visit_inline()
                         nodes.reference,       # backlink (in ToC)
                         nodes.system_message,  # auto-link (uses \hyperlink)
                         nodes.table,           # no anchor if with caption
                         nodes.target,          # may be inline or block-level
                         )
        if (isinstance(node, id_nodes)
            and not isinstance(node, id_exceptions)):
            self.out += self.ids_to_labels(node, pre_nl=True)
        return super().dispatch_visit(node)

    def ids_to_labels(self, node, set_anchor=True, protect=False,
                      newline=False, pre_nl=False) -> list[str]:
        """Return label definitions for all ids of `node`.

        If `set_anchor` is True, an anchor is set with \\phantomsection.
        If `protect` is True, the \\label cmd is made robust.
        If `newline` is True, a newline is added if there are labels.
        If `pre_nl` is True, a newline is prepended if there are labels.

        Provisional.
        """
        prefix = '\\protect' if protect else ''
        labels = [f'{prefix}\\label{{{id}}}' for id in node['ids']]
        if labels:
            if set_anchor:
                labels.insert(0, '\\phantomsection')
            if newline:
                labels.append('\n')
            if pre_nl:
                labels.insert(0, '\n')
        return labels
~~~
Maybe a similar approach could work in Sphinx, too.
