### Describe the bug

Revision [r10151 of `docutils`](https://sourceforge.net/p/docutils/code/10151/) (aka commit [`b25db649a5d073d76424e6434e12cdba53ed57e8`](https://repo.or.cz/docutils.git/commit/b25db649a5d073d76424e6434e12cdba53ed57e8) in the project's `git` repository) introduces a change that alters the label identifiers produced in the output of some Sphinx builds.

My understanding is that this should not negatively impact users -- the output documentation is still valid, I believe -- but it does cause a failure in one of our LaTeX test cases, [`test_latex_labels`](https://github.com/sphinx-doc/sphinx/blob/31e63d786aefcb54ba08fa6406a3579ec5ecdc8f/tests/test_builders/test_build_latex.py#L1956-L2017).

In particular, the expected label identifiers for a `figure` element and a `table` element differ; previously they were `id1` and `id2` respectively - after the `docutils` revision r10151, they become `id2` and `id3`.

### How to Reproduce

```sh
$ git clone https://github.com/sphinx-doc/sphinx.git && cd sphinx
$ git checkout 546170754f3f2f96c0d12176b2d2fb5688ca75ab

$ pip install '.[test]'
$ pip install git+https://repo.or.cz/docutils.git@b25db649a5d073d76424e6434e12cdba53ed57e8#subdirectory=docutils
$ pytest tests/test_builders/test_build_latex.py -k test_latex_labels
```
