> Using the CSS rules for an error admonition for an element without title is already possible via the ["container" directive](https://docutils.sourceforge.io/docs/ref/rst/directives.html#container):
> 
> ```rst
> .. container:: admonition error
>    
>    An "admonition" box without title!
> ```

This is not very intuitive. Such an approach needs to be documented per theme (listing whatever admonition CSS class names the theme supports).
