### Describe the bug

six has [this code](https://github.com/benjaminp/six/blob/1.17.0/six.py#L549-L554),

```python
try:
    advance_iterator = next
except NameError:
    def advance_iterator(it):
        return it.next()
next = advance_iterator
```

When building with sphinx 9.x, an autodoc warning is emitted that previously did not exist:
```WARNING: error while formatting signature for six.advance_iterator: list assignment index out of range [autodoc]```

This warning did not exist in earlier versions.
