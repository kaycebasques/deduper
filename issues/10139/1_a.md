### Describe the bug

In .rst file I use a word which starts with a german Umlaut. This usually worked for me nicely with Sphinx 3.5.3 + MikTeX.
It created a special Character index entry named Sonderzeichen, see upper snapshot.

.. index:: Ölversorgung

After Upgrade to Sphinx 4.4 and TeXLive the document build fails with a Latex error that did not point me anywhere.
By try and error I nailed it down to this index entry above. 



, Index Keyword starts with Umlaut,


### How to Reproduce

Use the following line in an .rst file

.. index:: Ölversorgung



### Expected behavior

Sphinx used to create an index entry before A named "special character" = "Sonderzeichen" in german.
See attached screenshot.

e.G.

Sonderzeichen
Ölversorgung, 52

A
Angström

B
...
